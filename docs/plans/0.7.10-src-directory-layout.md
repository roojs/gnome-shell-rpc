# 0.7.10 — `src/` layout, **Gsr** prefix, naming

**User goal:** Reorganize **`src/`** and **`tests/`** with literal names (installed **lib\*** dirs, **gresource**, binaries). Rename **`GnomeShellRpc` → `Gsr`**. Put **`meta-mini`** and harnesses under **`tests/`**. Shell sources sit in **`client/`** with no extra subfolder.

**Status:** **IN PROGRESS**. Phase 2b naming is applied. `gsr-server` and `gsr-client` build.

**🚫** No mass rename during 0.8. One mechanical PR per move.

**🔷** `Window` and `Workspace` move into `shared/`. They are snapshots. `Display` and `Compositor` are not.

**🔷** `ui/Display.vala` and `ui/Compositor.vala` are libmutter. They go in `server/libmutter-16/`, not loose on `server/`.

**ℹ️** Two `Display` classes, different wires. `ui/Display.vala` is `Meta-Display` (`list_windows`, activate, close). `rpc/helper/Display.vala` is `Helper-Display` (keybindings, pad OSD).

**✔️** Helper file is `Keybinding.vala`, so both can sit in `libmutter-16/`. Wire stays `Gsr-Mutter-Display`.

**ℹ️** One `Compositor` file: `ui/Compositor.vala` is `Meta-Compositor.get_window_actors`. `Server.vala` also aliases that wire name onto the real mutter object.

**🔷** Binaries are **`gsr-server`** and **`gsr-client`**. **`mutter-rpc`** and **`gnome-shell-rpc`** go.

**🔷** Client Shell dir and `.so` are **`libshell-16`**. Drop **`libshell-gi-16`**.

**🔷** Server wire classes sit next to `rpc/`, in **`libmutter-16/`**, **`libmutter-clutter-16/`**, **`libst-16/`**, **`libshell-16/`**. Not inside `rpc/`.

**🔷** Installed **`libmutter-rpc-16`**, **`libmutter-clutter-rpc-16`**, and typelib dir **`mutter-rpc-16`** stay. Those are the client `.so` names, not these server dirs.

**🔷** `meta-mini/` moves to `tests/`. Existing `install_data` for its hand-written `Meta-16.gir` keeps that path. No new install program. Typelib still comes from stock mutter.

**ℹ️** Today that code is inside `libmutter-clutter-rpc-16`, not the shell app. The app is `ShellApplication.vala` plus the gresource. It calls `Runtime.register()` and links the libs.

**🔷** `client/rpc/` is its own mini library, split out of that Clutter `.so`. `libmutter-rpc-16`, `libmutter-clutter-rpc-16`, `libst-rpc-16`, and `libshell-16` link it.

**ℹ️** GJS calls Meta (or Clutter, St, Shell). That code calls `call_value` in the mini library. It does not call back into the shell app.

**ℹ️** The app only starts it: `Runtime.register()` connects the socket, then calls `meta_register`, `st_register`, and the Shell signal hooks. Those functions live in the other libs. The mini library does not link them. The symbols stay unresolved and fill in when `gsr-client` loads every `.so`. Same trick the Clutter `.so` uses today (`--unresolved-symbols=ignore-all`).

**🔷** `shell-js-probe/` moves to `tests/shell-js-probe/`.

**🔷** Demo binary stays named `rpc-client`. Folder is `tests/ollm-demo-client/`.

**🔷** When demos are installed, they go under a demo prefix, not `bindir`. Not this phase. They stay `install: false`.

**✔️** Phase 2b — mapping below is applied. `Helper` is gone from the Vala namespace.

**🔷** Prefix is **`Gsr`**. Capital G, lowercase sr.

**ℹ️** `Meta`, `Clutter`, `St`, and `Shell` stay. GJS imports those. Generated stubs and hand classes that are those types stay in them (`Meta.BackgroundContent`, `Meta.RpcSubprocess`, `Shell.BlurEffect`).

**✔️** The segment is **`Meta`**, not `Mutter`. `libmutter` is the directory. The types are Meta. Wire names use `Mutter`.

**ℹ️** No top-level `Gsr.Rpc`. `rpc/` is under `server/` or `client/`, so the namespace is `Gsr.Server.Rpc` or `Gsr.Client.Rpc`.

**✔️** `HelperDisplay` (keybindings and pad OSD) is **`Gsr.Server.Meta.Keybinding`**. `Gsr.Server.Meta.Display` is the other one (`list_windows`, activate, close).

**🔷** A helper also has an RPC name. `Helper-` goes. The helper is not the object, so the wire is **`Gsr-Mutter-Window`**, not `Meta-Window`. `Meta-`, `Clutter-`, `St-`, and `Shell-` stay on the real object. Spelling is `Gsr`, not `GSR`.

**🔷** `ClutterHelper` becomes **`Gsr.Server.Clutter.Clutter`**. The wire stays the short name **`Gsr-Clutter`**.
