
```vala
public GLib.SList<Window> sort_windows_by_stacking(GLib.SList<Window> windows) {
	var windows_at = GnomeShellRpc.GiStub.Runtime.lease_ids_at_slist(
		(GLib.SList<GLib.Object>) windows);
	var response = GnomeShellRpc.GiStub.Runtime.call_values(
		"Meta-Display.sort_windows_by_stacking", this,
		OLLMrpc.args("v", windows_at));

		_list.append((Window) response.result.get(_i));

}
```

### A2 — `set_builtin_struts` — list of `Strut` **in**

**Shell** (`layout.js`):

```js
const strut = new Meta.Strut({rect: strutRect, side});
struts.push(strut);
workspace.set_builtin_struts(struts);
```

**Generated stub (wired):**

```vala
public void set_builtin_struts(GLib.SList<Strut> struts) {
	var struts_aay_builder = new GLib.VariantBuilder(new GLib.VariantType("aay"));
	for (unowned GLib.SList<Strut>? _struts_node = struts;
			_struts_node != null; _struts_node = _struts_node.next) {
		unsafe {
			uint8[] _struts_data = new uint8[sizeof(Strut)];
			*((Strut*) _struts_data) = _struts_node.data;
			struts_aay_builder.add_value(new GLib.Variant.from_bytes(
				new GLib.VariantType("ay"), new GLib.Bytes(_struts_data), true));
		}
	}
	var struts_aay = struts_aay_builder.end();
	GnomeShellRpc.GiStub.Runtime.call_values(
		"Meta-Workspace.set_builtin_struts", this,
		OLLMrpc.args("v", struts_aay));
}
```

**This repo:** memcpy each strut into Variant `aay` (same as single boxed `ay`). **✔️**

**libocrpc:** `Gi.convert_list` boxed branch. **✔️**
