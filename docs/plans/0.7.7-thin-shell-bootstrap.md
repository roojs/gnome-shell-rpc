# 0.7.7 — Thin shell bootstrap (no libshell for C boot)

**User goal:** nested **`mutter-rpc` + `gnome-shell-rpc`** boots (Wayland window). Everything else is a means — only do it if it unblocks that.

Checklist: `docs/guide-to-writing-plans.md`.

**Corridor loop (mandatory):**
1. **Live** — run `mutter-rpc --wayland --nested` (**~5s**); note the abort / wall.
2. **Mock** — reproduce that same failure under `gi-rpc-smoke.sh`. HelperMock / GiMock arms exist to **replay the live call path quickly** so we reach the crash site without a compositor — not to invent APIs or scout past the live wall.
3. **Fix on mock** — iterate until mock clears that wall.
4. **Back to live** — re-run nested Wayland (**~5s**); only then advance the live cursor.

**Live timeout:** **5s**. Abort / wall shows up well under that. If nested is still alive past ~5s without `terminate_with_error`, treat it as **probably booting** (success enough to stop watching for that run).

Mock does **not** count as product progress. Mock + helpers = **fast replay of the live crash**.
