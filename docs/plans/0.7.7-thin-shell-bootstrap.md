Same as **0.1** / **0.7** — nested tests only. **🚫** `meson install` over the live session.

## Purpose

**🔷** Stop using vendored **`libshell` C** to bootstrap **`gnome-shell-rpc`**. That path relinks upstream `shell-global.c` against **RPC Meta/Clutter stubs** and **client `libst`**, then fails one **`g_object_ref` / `st_*` / GType size** at a time.

**🔷** Replace with an **owned thin host** in `src/shell-client/` (and small GI stubs where needed) whose scope is **audited before code**, not discovered by nested CRITICALs.

**🚫 Forbidden (same class as reverted boot probes in 0.7.6 Phase A):**

- Commenting out or nooping **`st_*`**, **`meta_*`**, signal connects, or **`g_object_ref`** sites to “get past” bootstrap
- **`NULL` placeholders** for required `ShellGlobal` fields without a documented bootstrap exception
- Linking **client vendored `libst-16`** for GJS (`libst-rpc-16` only — see 0.7.6 Phase E)
- Growing **`shell-global-rpc-append.c`** line-by-line without an audit row marked **implemented**

## Architecture (target)

```
mutter-rpc (server)                    gnome-shell-rpc (client)
────────────────────                   ────────────────────────────
real Meta / Clutter / St               libmutter-rpc / libmutter-clutter-rpc / libst-rpc
stage, St widgets, settings…           GJS + upstream js/ (gresource or distro)
                                       thin ShellGlobal facade (our code)
                                       Meta.Context.run_main_loop → client loop RPC
                                       no libshell-16.so in bootstrap path
```

**ℹ️** **`libshell` C** is not the product shell — **JS is** ([`0.5-gnome-shell-js-layer.md`](0.5-gnome-shell-js-layer.md)). We may still ship **JS gresource** built from vendor `js/` (meson `shell-js/` slice) without linking **`libshell`**.

**ℹ️** **`Shell.*` GI** beyond bootstrap: add **stubs/helpers only when the audit row says so** — not a full `libshell-rpc` generator pass in this plan.

## Phase C — Thin host (replace libshell bootstrap) **🔷** **⏳**

**Remove:**

- **`gnome-shell-rpc`** link of **`libshell-16`** / **`libst-16`** for the **default product host** (legacy `-Dgnome_shell_client_libs` may remain gated for comparison until Phase E proves parity)
- **`_shell_global_init()`** + **`shell_global_attach_rpc_display()`** from vendored **`libshell`** in the default boot path
- **`shell-global-rpc-append.c`** appended to vendor **`shell-global.c`** (delete or freeze; no new lines)

**Add:**

- **`src/shell-client/`** thin host: connect RPC → `Runtime.register()` → minimal **`ShellGlobal` facade** satisfying **audit rows marked “owned C / RPC”**
- **`Meta.Context.run_main_loop`** / **`terminate_with_error`** on client (see [`main-loop-smoke.js`](../src/gjs-embed/main-loop-smoke.js), [`Helper-Context`](../src/rpc/helper/Context.vala))
- GJS context + search path / gresource loader **without** `_shell_global_get_gjs_context()` from **`libshell`**
- **`Shell.Global.get()`** via **minimal Shell GI stub** or small owned typelib — only symbols in audit table

**Replace with:**

- Each **`st_*` / settings / focus** bootstrap need → **audit row**: Helper RPC, server-side init, or explicit “deferred until main.js” (not noop)

**Exit:** nested **`shell-global-smoke.js`** passes **without** `libshell`; **`ldd gnome-shell-rpc`** shows **`libst-rpc-16`**, not **`libst-16`** / **`libshell-16`**.
