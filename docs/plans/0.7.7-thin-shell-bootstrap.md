## Purpose / architecture (context)

Replace vendored **`libshell` C** with an **owned thin host** + minimal **`Shell-16` facade** (`Shell.Global` + listed utils). Live Meta/Clutter/St stay on **`mutter-rpc`**; client holds leases. JS remains stock upstream.

```
mutter-rpc (server)                    gnome-shell-rpc (client)
────────────────────                   ────────────────────────────
real Meta / Clutter / St               libmutter-rpc / clutter-rpc / libst-rpc
                                       owned Shell-16 facade + GJS + js gresource
                                       no libshell-16.so
```
