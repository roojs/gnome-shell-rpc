## 2. Client dies mid-message

**ℹ️** `Connection.drain_readable` (`src/server/rpc/Connection.vala`) calls `GLib.error` when `bin.parse()` throws. A client that dies mid-message (seen 2026-10-03 16:50: `Unexpected early end-of-stream`) kills the whole server, so 1.2 never gets to tear down or restart. HUP between messages already goes through `on_input_ready` → `stop()`.

#### Remove — `drain_readable` parse catch

```vala
				} catch (GLib.Error e) {
					GLib.error("%s", e.message);
				}
```

#### Replace with — `drain_readable` parse catch

**💩** `⏳` Same as HUP. With the §1 OPC fix, base `stop()` marks waiting hooks replied and `Hook.emit` stops waiting once the connection stops, so no extra wake-up loop is needed.

```vala
				} catch (GLib.Error e) {
					GLib.warning("connection read: %s", e.message);
					this.stop();
					break;
				}
```
