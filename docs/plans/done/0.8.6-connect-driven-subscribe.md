# 0.8.6 — Connect-driven signal subscribe

**User goal:** nested **`mutter-rpc` + `gnome-shell-rpc`** stays up and chrome responds to pointer / keyboard. This cut makes a local GJS `.connect(name)` also request `RPC-Live-Subscribe.rpc_signal` for that name, so the server registers a handler and Notifications reach the client proxy.

Checklist: `docs/guide-to-writing-plans.md`.

**Status:** **✅** user 2026-10-02. Closed with 0.8. Host evals `resource:///org/gnome/shell-rpc/signals.js` before the shell script. `Shell.Signals.connect` / `disconnect` own the wire table. Client doc already records the wrap ([`../../signals-client.md`](../../signals-client.md)).

**Chosen:** wrap `GObject.Object.prototype.connect` (and `connect_after` / `connect_object`) in JS, injected from **our** GJS host before `init.js`. Not a GI `connect` on stub classes. Not `LD_PRELOAD`. Not linker `--wrap`. Not emit-time hooks.

**Docs:** [`../../signals-client.md`](../../signals-client.md) · [`../../signals-server.md`](../../signals-server.md)

**Unblocks:** GJS-visible hand `ensure_signal_subscribe` sites are gone. Vala-only remnants: Laters `before-update`, `style-changed`.

## Scope

**🔷** Pattern: GJS `.connect(name)` → local GObject handler → `Runtime.ensure_signal_subscribe(proxy, name)` → `RPC-Live-Subscribe.rpc_signal` → server `g_signal_connect` that name → Notification re-emitted on the client proxy.

**🚫** Vfuncs, class-struct slots, `vfunc_*`, `VfuncRelay`, `Helper-Actor.add_hook`, `Live.Hook`, `clicked` class-closure delivery.

**🚫** Forward every emission from a lease. **🚫** Subscribe at emit time (`g_signal_override_class_closure`, `g_signal_add_emission_hook`, `GSignalAccumulator`, `has_handler_pending` on dispatch). **🚫** `LD_PRELOAD`. **🚫** Linker `--wrap` of the stub `.so`. **🚫** GI method named `connect` on generated stubs (marshalling / `connect_after` never-lazy). **🚫** Vendor stock `js/` / `environment.js`. **🚫** Idle / Timeout as the subscribe flush. **🚫** OLLMchat / libocrpc edits from this tree.

## Why

```text
GJS .connect('stopped', handler)
  -> GObject.Object.prototype.connect (libgjs builtin)
  -> local GObject handler list
  -> Runtime.ensure_signal_subscribe
  -> RPC-Live-Subscribe.rpc_signal
```

GLib has no connect-time hook (`handler_insert` is static). Accumulators and emission hooks run on **emit**. The host evals JS before `init.js`. Same slot, always on.

Hand `ensure_signal_subscribe` call sites GJS `.connect()` replaced:

| Call site | Signal |
| --- | --- |
| `Meta.get_display()` | `workareas-changed` **✔️** removed |
| `St.Entry.clutter_text` | `text-changed`, `key-focus-in`, `key-focus-out` **✔️** removed |
| `Clutter.Actor.get_transition()` | `stopped` **✔️** removed |
| `St.Adjustment.add_transition()` | `stopped` **✔️** removed |

`Meta.Laters` `before-update` is Vala `signal_before_update.connect()` — this wrap does not see it. Leave that call site. `style-changed` after lease mint stays. GJS `.connect('clicked')` uses the wrap; there is no Vala `clicked` connect in the shell.

## Intended vs exists

```text
intended:
  GJS obj.connect(name, handler)
    -> original GObject.prototype.connect (GJS handler id unchanged)
    -> Shell.Signals.connect(obj, name, gjs_handler_id)

exists:
  wrap eval'd by ShellApplication before init.js
  Shell.Signals in shell-gi (name → our id, refs, GJS id map)
  Vala connect still hand-subscribed (Laters / style-changed)
```

Server contract does not change. One wire subscription per `(connection, lease, name)` already fans out to many local handlers.

## Inject

**Where:** `ShellApplication`, after `new Gjs.Context.with_search_path(...)`, **before** `eval_module_file(init.js)`.

**What:** `resource:///org/gnome/shell-rpc/signals.js`. Eval that file, then `Signals.install()`. Do not patch stock `environment.js`.

Wrap all three GJS builtins (they do **not** call each other):

```text
GObject.Object.prototype.connect
GObject.Object.prototype.connect_after
GObject.Object.prototype.connect_object
```

Each wrapper: call the original first (keep the GJS handler id), then `Shell.Signals.connect(this, name, id)`. `Shell.Signals.connect` no-ops when `rpc_lid == 0` or the object is not a `Live.Handle`. `prototype.disconnect` calls `Shell.Signals.disconnect_id(this, id)` then the original.

**Do not** use `GI_RPC_JS_OVERRIDE_DIR` as the ship path.

---

## Flow

```text
GJS obj.connect(name, handler)
  -> orig.connect (local handler id)
  -> Runtime.ensure_signal_subscribe(obj, name)
       not Live.Handle / rpc_lid == 0  -> pending or return
       already in signal_subs          -> return
       call_poll depth > 0             -> pending
       else                            -> RPC-Live-Subscribe.rpc_signal
```

Pending flush is on `register_handle` and on `do_call` returning to depth 0. Stack unwind, not `GLib.Idle`.
