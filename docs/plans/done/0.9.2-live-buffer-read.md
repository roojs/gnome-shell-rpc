# 0.9.2 — Live buffer call sites

**Status:** **done**. `from_bytes` and `read_exact` are in the installed libocrpc. The call sites below use them. The 16 client libraries and `gsr-server` rebuilt.

Checklist: [`docs/guide-to-writing-plans.md`](../../guide-to-writing-plans.md).

Proposed Vala follows [`docs/coding-standards.md`](../../coding-standards.md).

## Purpose

- 🔷 The memfd read loop and the memfd create/write belong on `OLLMrpc.Live.Buffer`. That API landed in OLLMchat `docs/bugs/done/2026-11-02-CLOSED-live-buffer-bytes.md`. This plan is the gnome-shell-rpc call sites.
- ✔️ Each copied loop now calls `read_exact` or `from_bytes`. Each caller keeps its own failure.
- ℹ️ Three server reads were the same loop and were not in the original fences: `src/server/libst-16/Clipboard.vala` `set_content`, `src/server/libst-16/DrawingArea.vala` `paint`, `src/server/libst-16/ImageContent.vala` `set_data`. They call `request.buffer.read_exact`. `tests/meta-mini/WindowActor.vala` `paint_to_content` does too.
- ℹ️ `new OLLMrpc.Live.Buffer(fd)` stays for `WaylandClient.spawnv`. That fd is a duplicated stdout pipe, not a byte array.
- 🚫 Do not edit libocrpc from this tree.

## Read call sites

Seek to 0, read until the byte count, fail if the count was not reached.

- `src/client/libmutter-clutter-rpc-16/overrides/Stage.override.vala` `paint_to_buffer` — throws
- `src/client/libmutter-clutter-rpc-18/overrides/Stage.override.vala` `paint_to_buffer` — throws
- `src/client/libmutter-rpc-16/overrides/WindowActor.override.vala` `paint_to_content` — returns null
- `src/client/libmutter-rpc-16/overrides/WindowActor.override.vala` `get_image` — returns null
- `src/client/libmutter-rpc-16/overrides/ShapedTexture.override.vala` `get_image` — returns null
- `src/client/libmutter-rpc-16/overrides/Selection.override.vala` `transfer_async` — throws
- `src/client/libmutter-rpc-16/overrides/SelectionSource.override.vala` `read_async` — throws

### 1. Stage `paint_to_buffer` — both overrides

**Why:** The frame read is `read_exact`.

**Where:** After the empty-fd check, in both stage overrides. The 18 method still passes `color_state`. Only the read changes.

**Depends on:** the bug's `read_exact`.

#### Remove

```vala
		var fd = response.buffer.fd;
		Posix.lseek(fd, 0, Posix.SEEK_SET);
		var got = 0;
		while (got < n_bytes) {
			var n = Posix.read(fd, (void*) &data[got], n_bytes - got);
			if (n <= 0) {
				break;
			}
			got += (int) n;
		}
		if (got < n_bytes) {
			throw new GLib.IOError.FAILED("paint_to_buffer: short read");
		}
```

#### Replace with

```vala
		if (!response.buffer.read_exact(data, n_bytes)) {
			throw new GLib.IOError.FAILED("paint_to_buffer: short read");
		}
```

## Send call sites

`memfd_create`, one `Posix.write`, close on failure, `lseek` 0, `new OLLMrpc.Live.Buffer(fd)`.

`from_bytes` throws. The `catch` keeps the reply the site already used.

### 6. Stage `paint_to_buffer` — both servers

**Why:** The frame is a `uint8[]` already.

**Where:** The memfd tail of `src/server/libmutter-clutter-16/ClutterStage.vala` and `src/server/libmutter-clutter-18/ClutterStage.vala`.

**Depends on:** the bug's `from_bytes`.

#### Remove

```vala
			var fd = Linux.memfd_create("gsr-stage", Linux.MemfdFlags.CLOEXEC);
			if (fd < 0 || Posix.write(fd, buf, n_bytes) != n_bytes) {
				if (fd >= 0) {
					Posix.close(fd);
				}
				request.connection.reply_error(request,
					(int) OLLMrpc.RpcErrorCode.INTERNAL_ERROR);
				return;
			}
			Posix.lseek(fd, 0, Posix.SEEK_SET);
			request.reply(new OLLMrpc.Response() {
				id = request.id,
			}, new OLLMrpc.Live.Buffer(fd));
```

#### Replace with

```vala
			try {
				var buffer = new OLLMrpc.Live.Buffer.from_bytes(buf, "gsr-stage");
				request.reply(new OLLMrpc.Response() {
					id = request.id,
				}, buffer);
			} catch (GLib.Error e) {
				request.connection.reply_error(request,
					(int) OLLMrpc.RpcErrorCode.INTERNAL_ERROR);
				return;
			}
```

**Where:** `src/client/libst-rpc-16/overrides/DrawingArea.override.vala`.

**Depends on:** the bug's `from_bytes`.

#### Remove

```vala
			var nbytes = stride * height;
			var fd = Linux.memfd_create("gsr-repaint", Linux.MemfdFlags.CLOEXEC);
			if (fd < 0) {
				return;
			}
			unowned uint8* pixels = (uint8*) surface.get_data();
			if (Posix.write(fd, pixels, (size_t) nbytes) != nbytes) {
				Posix.close(fd);
				return;
			}
			Posix.lseek(fd, 0, Posix.SEEK_SET);
			Gsr.Client.Rpc.call_value(
				"Gsr-St-DrawingArea.paint", this,

```

```vala

			var pixels = new uint8[nbytes];

			try {
				var buffer = new OLLMrpc.Live.Buffer.from_bytes(pixels, "gsr-repaint");
				Gsr.Client.Rpc.call_value(
					"Gsr-St-DrawingArea.paint", this,
```
