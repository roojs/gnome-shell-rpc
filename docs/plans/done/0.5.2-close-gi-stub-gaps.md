### Phase 3 — GObject IN args (leased handles in `values[]`)

**🔷** `✔️` **Managed** `Meta.`* **GObject IN** — generator emits `set_object`; `Runtime.wire_in_value` resolves `gsr-lease-id` → `uint64` on the wire. **No libocrpc change.**

**Baseline → after Phase 3:** wired 319→347, gaps 84→56 (−28 `not_wired`).

**🚫 Exception — foreign GObjects** (not in the emitted namespace): stay `not_wired` until a dedicated wire path exists. Examples: `Gio.File` in `Meta-Background.set_file`, `Gio.OutputStream` / `Gio.Cancellable` in async APIs, callbacks. These are **not** leased stubs; `Runtime` errors if they reach `wire_in_value` without `gsr-lease-id`.

**Remove:** managed GObject IN arg → `not_wired`.

**Add (two places, not in every stub):**

1. **Generator** — `type_is_managed_gobject(ns, …)` → wireable; emit `GLib.Value(typeof(T)); val.set_object(arg)`.
2. `GiStub.Runtime.call_values` — in the `values[]` loop: GObject + `gsr-lease-id` → `uint64` lease id.

**Examples wired:** `Meta-Window.change_workspace`, `Meta-Selection.set_owner`, `Meta-LaunchContext.set_workspace`, …

**Examples still gaps:** `Meta-Background.set_file` (`Gio.File`), `Meta-Selection.transfer_async` (`Gio.`* + callback), …

**Target stub** — `Meta.Window.change_workspace(Workspace workspace)`:

```vala
public void change_workspace(Workspace workspace) {
    var workspace_val = GLib.Value(typeof(Workspace));
    workspace_val.set_object(workspace);
    GnomeShellRpc.GiStub.Runtime.call_values(
        "Meta-Window.change_workspace",
        this,
        { workspace_val }
    );
}
```

**Runtime** (in `call_values` foreach — not a separate helper):

```vala
// GObject + gsr-lease-id → uint64 on wire
// GObject without lease (Gio.File, …) → GLib.error
// scalars / boxed / enum → pass through
```

**Wire shape:**

```text
Request.lease_id   = <from `this` via Runtime>
Request.values[n]  = uint64 <lease id>   // Runtime extracts from managed stub
```

**Server:** `Gi.convert_interface` — `uint64` → leased `Meta.`* pointer (already landed).

### Phase 5 — C arrays (`unmapped_arg`, 4)

**🔷** `✔️` **UTF8 / filename `string[]` IN** — generator maps GIR `ARRAY` of `UTF8` / `FILENAME` to `string[]` / `OLLMrpc.args` letter `as`. libocrpc `convert_array` aliases native `string[]` (not a `GLib.Variant` `"as"`).

**ℹ️** libocrpc already has pieces of C-array support. **That is not enough** for these four gaps:

| Already in libocrpc | Missing for Phase 5 |
| --- | --- |
| `StreamValue` write / read of native `string[]` (`STRING\|0x80`) | `type_vala` returns `""` for `GI.TypeTag.ARRAY` → **skip, no stub** |
| `StreamValue` numeric slabs via `GLib.Variant` (`"ai"` / `"au"` / …) | `value_suffix` has no `ARRAY` case → even a mapped `string[]` stays `not_wired` |
| `Gi.convert_array` / `scalar_array` | `convert_array` currently **requires** `typeof(GLib.Variant)` `"as"` / `"ai"` / … — a client `string[]` `GLib.Value` is `INVALID_PARAMS`. 8.4.6 specified `typeof(string[])` alias; the Variant path is a dead end (`StreamValue` does not write Variant `"as"`) |

**Baseline (now):** 4 `unmapped_arg`. None of them is a numeric C array.

| Symbol | GIR shape | Close how |
| --- | --- | --- |
| `Meta-WaylandClient.spawnv` | IN `filename[]` (`const char* const*`, zero-terminated) + `Meta.Display` + **`Gio.Subprocess` return** | **Wire argv** (this phase). **✔️** Return is foreign GObject — compositor-side only; `src/rpc/Server.vala` uses real mutter `spawnv`. |
| `Meta-Context.configure` | **INOUT** `argv` (`char***`) + sibling `argc` | **Deny.** Bootstrap only (`src/Main.vala` on the compositor). INOUT + length companion is 8.4.6 deferred. |
| `Meta-Context.add_option_entries` | `GLib.OptionEntry[]` (NULL-terminated struct array) | **Deny.** `GOptionEntry.arg_data` is a callback / out-pointer — not RPC-safe. |
| `Meta-Workspace.set_builtin_struts` | **GSList of `Meta.Strut`** (boxed), **not** a C array | **Deny** (or a later boxed-list IN phase). Misfiled in this bucket; same class as Phase 4 leftover `sort_windows_by_stacking`. |

**Remove:** `type_vala` default `""` for `ARRAY` of `UTF8` / `FILENAME`. **✔️**

**Add (generator — this repo):** **✔️**

1. `type_vala` — `GI.TypeTag.ARRAY` whose element is `UTF8` / `FILENAME` → `string[]`. Other element tags stay `""` (skip).
2. `dbus_letter` — that array → `as` (`OLLMrpc.args("as", argv)`).
3. OUT unpack uses `get_boxed()` on the native `string[]` `GLib.Value`.
4. Skip GIR `is_skip()` args (array-length companions). `spawnv` has none.

**Add (libocrpc — required, not optional):** `convert_array` UTF8 / FILENAME branch accepts `typeof(string[])` and sets `v_pointer` to that row (alias `request.args`, do **not** copy into a local `string[]`). Numeric Variant slabs stay as they are. **✔️**

**ℹ️** Filed: [`2026-08-25-gi-convert-array-as.md`](file:///home/alan/gitlive/OLLMchat/docs/bugs/2026-08-25-gi-convert-array-as.md) — native `string[]` accepted before the Variant gate.

**🚫** Do not invent a `Meta.Display.launch` / extra `spawnv` wrapper. **🚫** Do not wire `GOptionEntry[]`, INOUT `argv`, or GSList-of-boxed as if they were `string[]`.

**Example to wire** — `Meta.WaylandClient.spawnv(Display display, string[] argv)` (argv only; return still foreign):

```vala
public Gio.Subprocess spawnv(Display display, string[] argv) {
    var response = GnomeShellRpc.GiStub.Runtime.call_values(
        "Meta-WaylandClient.spawnv",
        this,
        OLLMrpc.args("oas", display, argv)
    );
    return (Gio.Subprocess) response.result.get(0);
}
```

**ℹ️** That return line is **not** Phase 5. `Gi.dispatch` only exports GTypes in `Bin.gtype_to_alias` (Meta `Gi.register`). `Gio.Subprocess` is not registered → `INVALID_PARAMS` even with argv on the wire. Same foreign-GObject rule as Phase 3 / Phase 6 (`Cogl.Texture`, `Gio.SubprocessLauncher`). **💩** Prefer **deny** `WaylandClient.spawnv` on the client stub so this gap closes; compositor spawn stays in-process on real mutter.

**Runtime:** no new helper. `call_values` already pass-through non-GObject `GLib.Value`s; `string[]` is not a leased stub.

**Wire shape (argv row):**

```text
Request.lease_id   = <WaylandClient>
Request.args[0]    = uint64 <Display lease>     // Phase 3
Request.args[1]    = string[]  (STRING|0x80)     // native GStrv, not Variant "as"
```

**Server:** `Gi.convert_array` — `string[]` → `GI.Argument.v_pointer` for the GIR `filename[]` IN arg.

**Examples still not this phase:** `Context.configure` / `add_option_entries` (deny), `Workspace.set_builtin_struts` (GSList boxed), `ButtonLayout` fixed arrays (Phase 7), `sort_windows_by_stacking` (GSList IN, Phase 4 leftover).

### Phase 7 — Struct fields (`unmapped_field`, 4)

**🔷** `✔️` `ButtonLayout` fixed-size array fields — `emit_struct` maps GIR `fixed-size` ARRAY of known element types → Vala `T[N]`.

**ℹ️** **Not an RPC / packing gap.** `prefs_get_button_layout` is already **wired** (OUT boxed `ay` memcpy of the whole struct). The wire already carries enough bytes. What fails is **codegen**: `type_vala` returns `""` for `GI.TypeTag.ARRAY` except UTF8/FILENAME `string[]`, so `emit_struct` skips every field and leaves an empty Vala struct. JS then has nothing to read on `layout.left_buttons`.

**ℹ️** GIR **does** have the info — fixed size and element type:

```xml
<field name="left_buttons" writable="1">
  <array zero-terminated="0" fixed-size="4">
    <type name="ButtonFunction" c:type="MetaButtonFunction"/>
  </array>
</field>
```

(`get_array_fixed_size()` → `4`, param type → `ButtonFunction` / `gboolean`.) We have not taught the generator to emit Vala `T[4]` from that. **Overrides** (`Meta.overrides`) are for when GIR is wrong or incomplete (e.g. `Compositor.get_window_actors list_elem=WindowActor`). For `ButtonLayout`, GIR is complete — prefer teaching `type_vala` / `emit_struct`. Override a field only if some typelib later lacks `fixed-size`.

**What we emit today** (`Meta_window_generated.vala`):

```vala
public enum ButtonFunction
{
	menu = 0,
	minimize = 1,
	maximize = 2,
	close = 3,
	last = 4,
}

public struct ButtonLayout
{
}

public void prefs_get_button_layout(out ButtonLayout button_layout) {
	var response = GnomeShellRpc.GiStub.Runtime.call_values(
		"Meta.prefs_get_button_layout", null);
	unsafe {
		var _blob = (GLib.Bytes) response.args.get(0).get_boxed();
		button_layout = *((ButtonLayout)*) _blob.get_data();
	}
}
```

**What mutter actually is** (`common.h` / GIR — four fixed arrays of length 4):

```c
struct _MetaButtonLayout
{
  MetaButtonFunction left_buttons[4];
  gboolean left_buttons_has_spacer[4];
  MetaButtonFunction right_buttons[4];
  gboolean right_buttons_has_spacer[4];
};
```

**Target Vala shape** (generator maps fixed-size `ARRAY` of ENUM / BOOLEAN):

```vala
public struct ButtonLayout
{
	public ButtonFunction left_buttons[4];
	public bool left_buttons_has_spacer[4];
	public ButtonFunction right_buttons[4];
	public bool right_buttons_has_spacer[4];
}
```

**Why it matters** — gnome-shell JS (not C main):

```js
// js/ui/windowPreview.js
const layout = Meta.prefs_get_button_layout();
this._closeButtonSide =
    layout.left_buttons.includes(Meta.ButtonFunction.CLOSE)
        ? St.Side.LEFT : St.Side.RIGHT;

// js/ui/screenshot.js — same idea
const buttonLayout = Meta.prefs_get_button_layout();
if (buttonLayout.left_buttons.includes(Meta.ButtonFunction.CLOSE))
    this._closeButton.add_style_class_name('left');
```

**Remove:** silent `continue` when `type_vala` returns `""` for a struct field (leaves empty `ButtonLayout`). **✔️**

**Add:** `emit_struct` — GIR fixed-size `ARRAY` of known element tags → Vala `public Elem name[N];`. Field layout must match C `sizeof` so the existing `ay` memcpy stays valid. **✔️**

**Gap rows closed:** `ButtonLayout.left_buttons`, `left_buttons_has_spacer`, `right_buttons`, `right_buttons_has_spacer`.

### Phase 8 — Deny policy + server gate

**🔷** `✔️` **Deny file** — `src/gi-stub-gen/Meta.deny`, loaded via `--deny-file` in meson emit. Optional trailing ``noop`` flag emits an empty stub instead of omitting.

**🔷** `✔️` **No-op emit** — generator: deny-file `Type.method noop` → empty body / `return true` / `return 0`; not a gap.

**🔷** `⏳` **Server** `Gi.dispatch` **gate** — mirror deny list so client cannot invoke dangerous symbols even if stub exists.

**Denied today:** `Meta-BackgroundContent.new` — actor already owns the content; `.new` is unused and would not put wallpaper on the stage (see Phase 6).

**💩** **Propose close** — awaiting review. Three knobs, not only deny:

| Knob | Stub? | Call does | Use when |
| --- | --- | --- | --- |
| **Deny** | omitted | missing symbol | A constructor / return would be a fake object, or we want the miss to be loud. `BackgroundContent.new` is this. |
| **No-op** | emitted, empty / `return true` | nothing, no RPC | Compositor already did it at process start. JS (or a ported `main`) may still call it and expect success. |
| **Local** | emitted, runs here | real work, no RPC | Pure function. RPC would be wrong; doing nothing would also be wrong. |

**🚫** Do not deny because the signature is hard (callback, `Gio.File`, GSList, …). That is a **gap**, not a deny or a no-op.

| Close? | Symbol | Knob | Why |
| --- | --- | --- | --- |
| ✔️ | `Context.configure` | **no-op** (`return true`) | gnome-shell **JS never calls this.** Only `src/main.c` (and our `Main.vala`) parse compositor argv before GJS starts. |
| ✔️ | `Context.add_option_entries` | **no-op** | **JS never.** `src/main.c` registers `gnome_shell_options` before `configure()`. |
| ✔️ | `Context.set_plugin_gtype` | **no-op** | **JS never.** `src/main.c` / our `Main.vala` pick the plugin type. |
| ✔️ | `Plugin.manager_set_plugin_type` | **no-op** | **JS never.** Replaced by `set_plugin_gtype`; only a comment in `gnome-shell-plugin.c`. |
| ✔️ temp | `Window.set_compositor_private` | **no-op** | See below. **Possible issue** — signed off only so we can move; revisit if JS (or a plugin) ever needs to *attach* an actor. |
| ✔️ | `unsigned_long_equal` / `unsigned_long_hash` | **no-op** | mutter uses them only as `GHashTable` key funcs for X11 XIDs (`x11/meta-x11-display.c` xids/alarms, `x11/meta-x11-group.c` groups). gnome-shell JS never calls them. Nested Wayland smoke does not need them. |
| — | `BackgroundContent.new` | **deny** (already) | Must return a content object. Empty constructor would still be a fake, not on the stage. |

**ℹ️** **`set_compositor_private` (plain English, flagged):** A window is a record (`Meta.Window`). What you see on screen is a separate actor (`Meta.WindowActor`). Mutter, when it creates the actor, calls **set** to remember “this actor belongs to this window.” The shell later calls **get** to find that actor (alt-tab, workspace thumbnails, skip-next-effect, …). **Get is already wired.** gnome-shell JS never calls **set** — only mutter’s actor constructor does. Client no-op = ignore a set. **Risk:** if we later need a client to attach an actor, this no-op will hide that. Temporary sign-off.
