GDM and LightDM are different display managers.

- **ℹ️** **GDM** lists `wayland-sessions/*.desktop` and runs `gnome-session --session=…`. `share/gnome-session/sessions/gnome.session` `RequiredComponents` includes `org.gnome.Shell`. GDM sets `GDMSESSION`. `X-GDM-SessionRegisters=true` is GDM’s key.
- **ℹ️** **LightDM** lists the same `wayland-sessions` directory and runs that file’s `Exec`. It does not read `X-GDM-*` and it does not open a `.session` file unless `Exec` is `gnome-session`. It does not set `GDMSESSION`.
- **ℹ️** The greeter shows `Name=`. That string is **GNOME Shell RPC**. `gsr-server`, `gsr-client`, `gsr-session`, and session id `gsr` (`--session=gsr`, `gsr.desktop`) are filenames. They are not the label in the list.
