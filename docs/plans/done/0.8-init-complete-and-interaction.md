## How we prove

1. **Look:** `./scripts/weston-gsr-session.sh` — nest stays until you close Weston.
   Add `--debug` for the log terminal and debug logs.
   **Score / agent:** `./scripts/weston-gsr-prove.sh` — **~15s** nest, **5s**
   settle after READY (early-stop on A4 / `Meta.is_restart`).
2. Property / Gi GValue: `GI_META_SMOKE=property-smoke` + `src/gjs-embed/property-smoke.js`.
3. Logs: `~/.cache/gnome-shell-rpc/{org.gnome.ShellRpc,mutter-rpc}.debug.log`
   plus autolaunch **stop reason** — [`nested-debug.md`](../../nested-debug.md)
   before gdb (default prove SIGKILLs on A4).
4. Mock (`gi-rpc-smoke.sh`, `tests/call-sync-repro/`) only for a **named** RPC gap.
5. `GI_RPC_JS_OVERRIDE_DIR` only when deliberately bisecting — not default.
