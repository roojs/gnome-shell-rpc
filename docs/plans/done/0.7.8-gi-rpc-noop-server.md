## Agent rules — mock import debugging **🔷**

Follow these when working this plan. **🚫** Do not improvise alternate harnesses.

| Do | How |
| --- | --- |
| **Repro** | `./scripts/gi-rpc-smoke.sh run` — one run (~1–2 s). **🚫** No multi-run loops unless the user asks. |
| **Override one JS file** | `GI_RPC_JS_OVERRIDE_DIR=src/shell-js` — sparse dir mirroring `org/gnome/shell/…` paths; runtime GResource overlay (debug only). |
| **Override whole tree** | `GNOME_SHELL_JS_DIR` — boot from disk; optional `prepare-js-override.sh` to clone vendor. |
| **Edit** | Change e.g. `src/shell-js/ui/messageList.js` by hand — comment out classes, etc. **No codegen.** |
| **Trace pin** | `GI_RPC_REGISTER_CLASS_TRACE=1 ./scripts/gi-rpc-smoke.sh run` — last `register-class-trace` lines before crash. |
| **Stub fix** | Compare failing class base to `src/gi-stub` / GIR; rebuild Vala; rerun smoke. |

| **🚫** Do not | Why |
| --- | --- |
| Meson/gresource overlay for JS bisect | Use `GI_RPC_JS_OVERRIDE_DIR` or `GNOME_SHELL_JS_DIR`. |
| Python / chop scripts | Edit the JS file. |
| Bisect env vars / terminate-as-bisect | Edit the JS file. |
| Module-only smokes as primary heap repro | Full `init.js` is the repro. |
| Multi-run statistical loops | One smoke (~2 s) is enough. |
| Nested pass as mock pass | Confirm on nested before closing. |

**ℹ️** `GI_RPC_JS_OVERRIDE_DIR` builds a runtime GResource overlay — later `resources_register` wins on `resource:///org/gnome/shell/…` lookup. Debug-only.

## How libocrpc mock mode works (shipped RPC-1.7)

**Calling `register_mock` switches the server into mock mode.** You do **not** implement or call `GiMock` yourself — it is internal to libocrpc.

```
Ffi  →  RPC-Daemon, RPC-Live-Callback.*, …
Helper  →  your MockDispatch object (return true if handled)
GiMock  →  automatic when helper returns false (GIR typed empties, no C invoke)
```

**Real compositor** (no `register_mock`):

```
Ffi  →  …
Gi   →  real g_function_info_invoke
```

**Your job in this repo:** one **`HelperMock`** class — `switch (request.method)` for `Helper-*`, `RPC-Bootstrap.*`, etc. Return **`true`** + `reply()` when matched. Return **`false`** for everything else → libocrpc runs **`GiMock`** for you.

## Architecture

```
gi-rpc-mock                         gnome-shell-rpc / gjs-embed
───────────                         ───────────────────────────
Gi.register(Meta|Clutter|St)   ←→   stub .so → Runtime.call_values
Request.register(RPC-Daemon)        import panel.js / registerClass
Request.register_mock(HelperMock)
  true  → Helper switch handles call
  false → GiMock (inside Request.dispatch)
```

| Call kind | Handler |
| --- | --- |
| `RPC-Daemon.*`, `RPC-Live-Callback.*` | **Ffi** |
| `Helper-*`, `RPC-Bootstrap.*`, … | **`HelperMock.dispatch`** — return **true** |
| `Meta-*`, `St-*`, `Clutter.*`, … | **`GiMock`** (libocrpc) — helper returns **false** |

Boot order: **`Gi.register("Meta"|"Clutter"|"St", "16")`** then **`register_mock`** (GiMock uses same `Gi.types` / `namespaces` lookup as real Gi).
