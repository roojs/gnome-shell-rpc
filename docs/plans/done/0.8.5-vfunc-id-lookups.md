# 0.8.5 — Vfunc id lookups (`vfunc_id` + `hook_id`, not the name string)

**User goal:** nested mutter-rpc + gnome-shell-rpc stays up and chrome responds — this cut stops hashing `"allocate"` on every layout/event.

Checklist: `docs/guide-to-writing-plans.md`.

**Status:** ✔️ archived 2026-09-19 — §1–§4 landed (`e1a7c46`, 2026-09-17). Fire is `vfuncs.get(ActorVfuncIds.*_id)` / `LayoutManagerVfuncIds.*_id`; `add_hook` is `"it"`.

**Bug:** [`../../bugs/done/2026-09-17-vfunc-id-lookups.md`](../../bugs/done/2026-09-17-vfunc-id-lookups.md)

**Upstream:** OLLMchat RPC-1.10 — libocrpc already exposes `Gi.vfunc_offset` and `hook_id`. **No OLLMchat edits.**

**Unblocks:** cheaper Helper fire after 0.8.2 name-keyed `vfuncs`.

---

## Purpose

- **🔷** Local (no socket): `vfunc_name` → `vfunc_id` via `Gi.vfunc_offset`.
- **🔷** Runtime registration (socket up): `add_hook(vfunc_id, hook_id)` — `"it"`. Name does not cross the wire.
- **🔷** Fire: `vfuncs.get(vfunc_id)` then `hook.emit` (already sends `hook_id`).
- **🔷** Generator must emit the `vfunc_id` next to `bind_vfunc`, because `relay=1` slots are generated.
- **🔷** Generator also emits Helper ID statics + `register_vfunc_ids()` for types with `helper=1`. `add_hook` and fire stay hand.

---

## Names

- **🔷** `vfunc_name` — string in our typelib / `relay=1` list / `always[]`.
- **🔷** `vfunc_id` — int, `Gi.vfunc_offset`.
- **🔷** `hook_id` — int, `RPC-Live-Callback.register` / `Live.Invoke.id`.

---

## Three places (do not mix)

- **🔷** **Generator** — `emit_object_class_slots`: `bind_vfunc` into the client stub (`--out`). Same `relayed` list → Helper ID fragment (`--helper-out`) when the type has `helper=1`.
- **🔷** **Client override (hand)** — `Actor.override.vala` `relay_attach`; `LayoutManager.override.vala` `ensure_helper_peer`.
- **🔷** **Server helper (hand)** — `add_hook`, fire `vfuncs.get(…)`, `vfuncs` map, `style_changed_id`. Generated statics live in the `--helper-out` fragment.

`VfuncRelay.overridden` stays phase-local (name set per GType). No RPC.

---

## 1. Generator — `bind_vfunc` also fills `vfunc_id`

**Why:** Generated stubs know `ns` / `class_name` / each `relay=1` field. The override must not hard-code those triples.

**Where:** `emit_object_class_slots`, the `if (relayed.size > 0)` emit.

**Depends on:** none.

#### Remove

```vala
				stream.puts(@"
		internal uint64 bind_vfunc(string name) {
			switch (name) {
");
				foreach (var rname in relayed) {
					var vala = this.vala_ident(rname);
					stream.puts(@"			case \"$(rname)\":
				return this.relay_$(vala)();
");
				}
				stream.puts(@"			default:
				return 0;
			}
		}
");
```

#### Replace with

`out vfunc_id` is the typelib class-struct offset. `hook_id` is still the trampoline.

```vala
				stream.puts(@"
		internal uint64 bind_vfunc(string name, out int vfunc_id) {
			vfunc_id = -1;
			switch (name) {
");
				foreach (var rname in relayed) {
					var vala = this.vala_ident(rname);
					stream.puts(@"			case \"$(rname)\":
				vfunc_id = OLLMrpc.Gi.vfunc_offset(\"$(ns)\", \"$(class_name)\", \"$(rname)\");
				return this.relay_$(vala)();
");
				}
				stream.puts(@"			default:
				return 0;
			}
		}
");
```

- **ℹ️** Re-run the stub generator after this emit change.
- **🚫** Do not emit a second string HashMap. Offset cache already lives in `Gi.vfunc_offset`.

### 1b. `--helper-out` — Helper ID fragment

**Why:** The `relayed` list already has `ns` / `class_name` / `rname`. Helper fire needs those ints as statics. Do not copy the triples by hand.

**Where:** `Application.vala` new `--helper-out=`; `Generator.emit` writes a second file after the client stub. Collect rows in `emit_object_class_slots` when `relayed.size > 0` **and** the type has `helper=1`.

**Depends on:** none (same pass as §1).

#### Add — `Application.vala` option (next to `--out`)

```vala
		private static string opt_helper_out = "";
```

```vala
			{ "helper-out", 0, GLib.OptionArg.FILENAME, ref opt_helper_out,
				"Output Helper vfunc-id fragment (emit)", "FILE" },
```

Reset `opt_helper_out` in `command_line` with the other opts. Pass into `Generator`:

```vala
					var gen = new Generator() {
						deny = deny,
						noop = noop,
						temporary = temporary,
						overrides = overrides,
						signal_prefer = signal_prefer,
						missing_out_path = Application.opt_missing_out,
						helper_out_path = Application.opt_helper_out,
					};
					gen.emit(ns, Application.opt_out);
```

`--helper-out` is optional. Meta / St emit omit it. Clutter emit always passes it so meson has a stable second output (file may be comment-only if no `helper=1`).

#### Add — `Generator.vala` fields + collect in `emit_object_class_slots`

```vala
		public string helper_out_path = "";

		private class HelperIds : GLib.Object
		{
			public string class_name { get; set; }
			public string ns { get; set; }
			public Gee.ArrayList<string> slots { get; set; }
		}

		private Gee.ArrayList<HelperIds> helper_ids = new Gee.ArrayList<HelperIds>();
```

Clear `helper_ids` at the start of `emit()`. After the existing `bind_vfunc` emit, still inside `if (relayed.size > 0)`:

```vala
				if (this.overrides.has_key(class_name)
						&& this.overrides.get(class_name).has_key("helper")
						&& this.overrides.get(class_name).get("helper") == "1") {
					var row = new HelperIds() {
						class_name = class_name,
						ns = ns,
						slots = new Gee.ArrayList<string>(),
					};
					foreach (var rname in relayed) {
						row.slots.add(rname);
					}
					this.helper_ids.add(row);
				}
```

#### Add — `Generator.emit` after the client stub is written (before return)

Left-hand name is `$(rname)_id`. One line. No wrap.

```vala
			if (this.helper_out_path != "") {
				var hs = GLib.FileStream.open(this.helper_out_path, "w");
				if (hs == null) {
					throw new GLib.IOError.FAILED("cannot write " + this.helper_out_path);
				}
				hs.puts("/* Generated by gi-stub-gen — do not edit */\n");
				if (this.helper_ids.size > 0) {
					hs.puts(@"
namespace GnomeShellRpc.Rpc.Helper
{
");
					foreach (var row in this.helper_ids) {
						hs.puts(@"	internal class $(row.class_name)VfuncIds
	{
");
						foreach (var rname in row.slots) {
							var vala = this.vala_ident(rname);
							hs.puts(@"		internal static int $(vala)_id;
");
						}
						hs.puts(@"
		internal static void register_vfunc_ids()
		{
");
						foreach (var rname in row.slots) {
							var vala = this.vala_ident(rname);
							hs.puts(@"			$(vala)_id = OLLMrpc.Gi.vfunc_offset(\"$(row.ns)\", \"$(row.class_name)\", \"$(rname)\");
");
						}
						hs.puts(@"		}
	}
");
					}
					hs.puts("}\n");
				}
			}
```

- **🔷** Emit `$(class_name)VfuncIds` (sibling class). Vala cannot declare `class Actor` twice.
- **🔷** Statics are `internal`. Fire uses `ActorVfuncIds.allocate_id`. `rpc_register` calls `ActorVfuncIds.register_vfunc_ids()`.
- **🚫** Do not emit `style_changed_id` here. That slot is `St.Widget`, not a Clutter.Actor `relay=1` field.

#### Add — `Clutter.overrides`

```
Actor helper=1
LayoutManager helper=1
LayoutManager.get_preferred_width  relay=1
LayoutManager.get_preferred_height relay=1
LayoutManager.allocate             relay=1
```

`LayoutManager` `relay=1` also emits client `bind_vfunc` (same §1 shape). `ensure_helper_peer` then uses it — see §4.

## 2. `Actor.override.vala` — `relay_attach` (hand)

**Why:** Phase B. Loop still has `vfunc_name`. Wire becomes `"it"`.

**Where:** foreach + `style_changed` (not a Clutter.Actor `relay=1` slot).

**Depends on:** §1 (generated `bind_vfunc` signature).

#### Remove

```vala
		foreach (var name in overridden) {
			var id = this.bind_vfunc(name);
			if (id == 0) {
				continue;
			}
			GnomeShellRpc.call_value(
				"Helper-Actor.add_hook", this,
				OLLMrpc.args("st", name, id));
		}
		/* St.Widget::style-changed — not a Clutter.Actor Class slot, so
		 * VfuncRelay.overridden never names it. Always register. */
		var style_id = this.relay_style_changed();
		if (style_id != 0) {
			GnomeShellRpc.call_value(
				"Helper-Actor.add_hook", this,
				OLLMrpc.args("st", "style_changed", style_id));
		}
```

#### Replace with

```vala
		foreach (var name in overridden) {
			var vfunc_id = -1;
			var hook_id = this.bind_vfunc(name, out vfunc_id);
			if (hook_id == 0) {
				continue;
			}
			GnomeShellRpc.call_value(
				"Helper-Actor.add_hook", this,
				OLLMrpc.args("it", vfunc_id, hook_id));
		}
		/* St.Widget::style-changed — not a Clutter.Actor Class slot. */
		var style_hook_id = this.relay_style_changed();
		if (style_hook_id != 0) {
			var style_vfunc_id = OLLMrpc.Gi.vfunc_offset("St", "Widget", "style_changed");
			GnomeShellRpc.call_value(
				"Helper-Actor.add_hook", this,
				OLLMrpc.args("it", style_vfunc_id, style_hook_id));
		}
```

## 3. `ClutterActor.vala` — Helper map + `add_hook("it")` + fire (hand)

**Why:** Server stores by slot. Fire must not hash the name.

**Where:** `vfuncs` field, `rpc_register`, `add_hook`, every `vfuncs.get("…")` and empty-map pop.

**Depends on:** §1b (generated `$(rname)_id` + `register_vfunc_ids()`).

#### Remove

			= new Gee.HashMap<string, OLLMrpc.Live.Hook>();

```vala

			get; set; default = new Gee.HashMap<int, OLLMrpc.Live.Hook>();
		}
		static int style_changed_id;
```

Relay=1 IDs come from the §1b fragment. Only `style_changed_id` is hand (`St.Widget`).

#### Remove

```vala

```

#### Replace with

```vala
				"add_hook", "it",
```

#### Add — after `register_live` in `rpc_register`

`Server.start` must `Gi.register` Clutter/St **before** `Helper.rpc_register()` — `Gi.vfunc_offset` needs the typelib.

```vala
			ActorVfuncIds.register_vfunc_ids();
			style_changed_id = OLLMrpc.Gi.vfunc_offset("St", "Widget", "style_changed");
```

#### Remove

```vala
		public void add_hook(OLLMrpc.Request request,string vfunc_name, uint64 callback_id)
		{
			var peer = request.connection.leases.get((int) request.lease_id) as Actor;
			if (peer == null
					|| !request.connection.callbacks.has_key((int) callback_id)) {
				request.connection.reply_error(request,
					(int) OLLMrpc.RpcErrorCode.INVALID_PARAMS);
				return;
			}
			peer.vfuncs.set(vfunc_name,
				request.connection.callbacks.get((int) callback_id));
			request.reply(new OLLMrpc.Response());
		}
```

#### Replace with

```vala
		public void add_hook(OLLMrpc.Request request, int vfunc_id, uint64 hook_id)
		{
			var peer = request.connection.leases.get((int) request.lease_id) as Actor;
			if (peer == null
					|| !request.connection.callbacks.has_key((int) hook_id)) {
				request.connection.reply_error(request,
					(int) OLLMrpc.RpcErrorCode.INVALID_PARAMS);
				return;
			}
			peer.vfuncs.set(vfunc_id,
				request.connection.callbacks.get((int) hook_id));
			request.reply(new OLLMrpc.Response());
		}
```

Fire: each `this.vfuncs.get("NAME")` → `this.vfuncs.get(matching_id)`. Empty pop `HashMap<string, …>` → `HashMap<int, …>`.

| Old get | New get |
| --- | --- |
| `"get_preferred_width"` | `ActorVfuncIds.get_preferred_width_id` |
| `"get_preferred_height"` | `ActorVfuncIds.get_preferred_height_id` |
| `"allocate"` | `ActorVfuncIds.allocate_id` |
| `"event"` (`event()` and `fire_button_press`) | `ActorVfuncIds.event_id` |
| `"captured_event"` | `ActorVfuncIds.captured_event_id` |

## 4. LayoutManager — same shape (IDs from §1b)

**Why:** Same `"st"` / string map. After §1c, `relay=1` + `helper=1` give `bind_vfunc` and generated IDs.

**Where:** `ClutterLayoutManager.vala` field / `rpc_register` / `add_hook` / three `get`s; `LayoutManager.override.vala` `ensure_helper_peer`.

**Depends on:** §1b / §1c.

- **🔷** `"add_hook", "it"`. Map `HashMap<int, Live.Hook>`.
- **🔷** `rpc_register` after `register_live`: `LayoutManagerVfuncIds.register_vfunc_ids();` (no hand `Gi.vfunc_offset`).
- **🔷** Fire `get`s use `LayoutManagerVfuncIds.get_preferred_width_id` / `get_preferred_height_id` / `allocate_id`.
- **🔷** `ensure_helper_peer` uses generated `bind_vfunc` (same `"it"` as §2).

#### Remove

```vala
		GnomeShellRpc.call_value("Helper-LayoutManager.add_hook", peer,
			OLLMrpc.args("st", "get_preferred_width", this.relay_get_preferred_width()));

		GnomeShellRpc.call_value("Helper-LayoutManager.add_hook", peer,
			OLLMrpc.args("st", "get_preferred_height", this.relay_get_preferred_height()));

		GnomeShellRpc.call_value("Helper-LayoutManager.add_hook", peer,
			OLLMrpc.args("st", "allocate",this.relay_allocate()));
```

#### Replace with

```vala
		var vfunc_id = -1;
		var hook_id = this.bind_vfunc("get_preferred_width", out vfunc_id);
		GnomeShellRpc.call_value("Helper-LayoutManager.add_hook", peer,
			OLLMrpc.args("it", vfunc_id, hook_id));
		hook_id = this.bind_vfunc("get_preferred_height", out vfunc_id);
		GnomeShellRpc.call_value("Helper-LayoutManager.add_hook", peer,
			OLLMrpc.args("it", vfunc_id, hook_id));
		hook_id = this.bind_vfunc("allocate", out vfunc_id);
		GnomeShellRpc.call_value("Helper-LayoutManager.add_hook", peer,
			OLLMrpc.args("it", vfunc_id, hook_id));
```

Three explicit slots. **🚫** Do not wrap them in a `string[]` / `foreach`. Hand `relay_*` bodies stay. Generator only adds `bind_vfunc` + the Helper ID fragment.
