## Purpose

0.5.1 proved the emit path. This plan owns **closing the gap list** so generated Meta client stubs can replace hand `meta-mini` without silent holes.

Two distinct knobs:

| Knob | Tool | Resolves |
|------|------|----------|
| **Wire** | `Generator` + `Runtime` + libocrpc `Gi.convert` | `not_wired`, most `skipped` |
| **Deny** | `--deny` / deny file (see Application TODO) | callbacks, unsafe mutator blast radius, symbols we never RPC |

**ℹ️** Not every Meta symbol should be wired. Some gaps close by **deny**, not codegen.

## Gap taxonomy (attack order)

Work top-down. Rebuild and re-read `Meta_window_generated.missing.md` after each phase; update baseline counts in this plan when a phase lands.

### Phase 1 — ENUM / FLAGS scalars

**🔷** `✔️` **Largest `not_wired` bucket.** `value_suffix()` + emit casts for `GI.InfoType.ENUM` / `FLAGS` via `INTERFACE` tag.

**Baseline → after Phase 1:** wired 250→291, gaps 153→112 (−41 `not_wired`).

---

### Phase 2 — BOXED structs (e.g. `Mtk.Rectangle`)

**🔷** `⏳` **Second `not_wired` bucket.** Rectangles, transforms, monitor geometry, etc.

**Blocked on:** libocrpc `Gi.convert` boxed support (8.4.5).

**Remove:** boxed IN/OUT/return → `not_wired`.

**Add:** generator boxed `GLib.Value` pack/unpack once convert exists; reuse `shared/Rectangle.vala` patterns where typelib matches.

**Examples:** `Meta-Window.get_frame_rect`, `Meta-Window.get_buffer_rect`, `Meta-Display.get_monitor_geometry`, `Meta-WindowConfig.get_rect` / `set_rect`, …

---

### Phase 3 — GObject IN args (leased handles in `values[]`)

**🔷** `⏳` Instance methods that take another `Meta.*` object as IN (not just `lease_id` on `this`).

**Blocked on:** libocrpc OBJECT in `Request.values` (8.4.5).

**Remove:** GObject IN arg → `not_wired`.

**Add:** emit leased-object refs in positional `values` (wire lease id, not client stub pointer).

**Examples:** `Meta-Window.change_workspace`, `Meta-Selection.set_owner`, `Meta-WaylandClient.owns_window`, …

---

### Phase 4 — GList / GSList returns (`unmapped_return`, 8)

**🔷** `⏳` **Skipped today** — no stub at all.

**Remove:** `unmapped_return` for container returns.

**Add:** `type_vala` + emit for `GList`/`GSList` of GObject elements; unpack via `response.result` rows (or extend `Runtime.call_list` to positional wire).

**Examples:** `Meta-Display.list_all_windows`, `Meta-Workspace.list_windows`, `Meta-Compositor.get_window_actors`, `Meta-Display.get_tab_list`, …

**ℹ️** This unblocks replacing hand `Display.list_all_windows` snapshot path when server returns real leases.

---

### Phase 5 — C arrays (`unmapped_arg`, 4)

**🔷** `⏳` `argv`, `GOptionEntry`, builtin struts arrays.

**Remove:** `unmapped_arg` skips.

**Add:** array marshalling in generator + libocrpc (or deny if only used at bootstrap — e.g. `Meta-Context.configure` may stay hand/denied).

---

### Phase 6 — Constructors (`constructor`, 10)

**🔷** `⏳` `Type.new` / factory methods.

**Remove:** constructor skip.

**Add:** emit `new` as RPC factory; server returns lease id; client stub attaches `gsr-lease-id`.

**Examples:** `Meta-WaylandClient.new`, `Meta-Background.new`, `Meta-WindowConfig.new`, …

**ℹ️** Overlaps 0.5 **stub identity** — confirm lease vocabulary matches `Notification.id`.

---

### Phase 7 — Struct fields (`unmapped_field`, 4)

**🔷** `⏳` `ButtonLayout` array fields.

**Remove:** silent field skip inside emitted struct.

**Add:** array field types in `type_vala`, or deny struct if never needed client-side.

---

### Phase 8 — Deny policy + server gate

**🔷** `⏳` **Deny file** (Application TODO) — load alongside `--deny`.

**🔷** `⏳` **Server `Gi.dispatch` gate** — mirror deny list so client cannot invoke dangerous symbols even if stub exists.

**Candidates to deny (not wire):** `Meta-Plugin.*_completed` vfuncs, `Meta.exit` / `Meta.restart`, `foreach_*` with callbacks, debug/verbose prefs helpers, X11-only paths if nested smoke is Wayland-only.

**ℹ️** Denied symbols drop out of **Gaps**; track them in the deny file, not in `missing.md` gap total.

---

### Phase 9 — Replace hand `meta-mini`

**🔷** `⏳` Link `metamini` from generated Vala + deny file instead of hand `Display.vala` / `Window.vala`.

**Prerequisite:** smoke paths wired (launch, list/focus, minimize/unminimize) with **Gaps = 0** or remaining gaps explicitly denied.
