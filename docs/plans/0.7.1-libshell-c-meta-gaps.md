## Purpose

**`libshell-16.so`** (vendor gnome-shell C) links **`libmutter-rpc-16`**, not **`libmutter-16`**. The linker needs **`meta_*` C symbols** from stock **`meta/*.h`**. Ten are missing today.

**ℹ️** These are **not** the gi-stub-gen GJS scoreboard. Generator walks **`GIRepository`** / introspectable API → **`Meta_window_generated.missing.md` Gaps → 0**. These ten are **`introspectable="0"`** in stock **`Meta-16.gir`** (or live on **opaque** `MetaSettings` / `MetaGroup` records) → **invisible to gi-stub-gen**, still **required at C link time** for `libshell`.

**🔷** Treat them like the rest of 0.5 / 0.6: **generator / Helper where we care about behaviour**, **documented C noop** where we do not — same rules as [`Meta.deny` noop](../src/gi-stub-gen/Meta.deny) / 0.5.5 Priority E, but for **C exports**.

**🚫** Do not invent **`meta_*` names** or headers. Signatures match **`/usr/include/mutter-16/meta/*.h`**.

**🚫** Do not satisfy these by linking stock **`libmutter-16`** into the shell client process.

## Policy: Wayland-only — no X11 client

**🔷** **`✅` User confirmed:** we are **not** supporting X11 in the shell client. Nested / product path is **Wayland-only** (real compositor + RPC shell).

**🚫** No **`Rpc.Helper.X11Display`**, no X11 event forwarding, no Xlib **`Display*`** proxy, no system-tray-over-X11 goal for 0.7 / 0.7.1.

**🔷** All **X11-shaped `meta_*`** below export **permanent noops** from **`libmutter-rpc-16`** — enough for **`libshell`** to link; upstream tray / X11 group code becomes dead at runtime (returns NULL / no-op / `0`).

| # | C symbol | Treatment |
| --- | --- | --- |
| 3 | `meta_display_get_x11_display` | **noop → NULL** |
| 4 | `meta_x11_display_get_xdisplay` | **noop → NULL** |
| 5 | `meta_x11_display_get_xroot` | **noop → `None`** |
| 6 | `meta_x11_display_set_stage_input_region` | **noop** (ignore rects) |
| 7 | `meta_x11_display_add_event_func` | **noop → `0`** |
| 8 | `meta_x11_display_remove_event_func` | **noop** |
| 9 | `meta_group_list_windows` | **noop → NULL** |
| 10 | `meta_window_x11_get_group` | **noop → NULL** |

**ℹ️** **`meta_x11_display_lookup_xwindow`** is already exported by **`libmutter-rpc-16`** today — treat as **noop / not supported** if called without X11 (may return **`None`**); **🚫** do not grow real X11 semantics for it in this plan.

**ℹ️** Optional later: build **`libshell`** with **`src/tray/`** omitted in meson to avoid pulling legacy tray objects — **not required** if noops satisfy the linker.
