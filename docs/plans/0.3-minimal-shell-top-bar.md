## Purpose

- **🔷** First UI **outside** the compositor process: GTK4 top bar as a normal Wayland client.
- **🔷** One mutating RPC action proves the split (`Window.minimize` on focused window).
- **🔷** `kill -9` the panel → nested apps and compositor stay up; relaunch panel from `list_windows`.

---

## Server tasks (this repo, plugin)

- **🔷** `⏳` Mutating methods: `Window.minimize`, `Window.unminimize`, `Window.activate`, `Window.close` — dispatch on server, run on real `MetaWindow`.
- **🔷** `⏳` Plugin still completes map/minimize/destroy **locally** (libdefault-style). Notify client; **do not** wait for client “effect completed”.
- **ℹ️** Notifications for live objects: still **`export()` + `Notification.id` + `object_type`** — no `payload` field ([OLLMchat 8.3.3 withdrawn](file:///home/alan/gitlive/OLLMchat/docs/plans/8.3.3-notification-gobject-payload.md)).

---

## Client tasks (this repo, `shell/` or similar)

- **🔷** `⏳` Vala app: `Client` with `live_handles: true`, connect to `MUTTER_RPC_SOCKET`, subscribe to focused window / workspace.
- **🔷** `⏳` GTK4 / libadwaita: clock / status strip as Wayland surface (layer-shell or protocol mutter already speaks — pick in open questions).
- **🔷** `⏳` One button → `Window.minimize` on focused window handle.
- **🔷** `⏳` Shadow object graph from handles; reconnect via `Display.list_windows`.
- **🚫** Do not load GNOME Shell extensions in this phase.
- **🚫** Do not rewrite gnome-shell JS here.

Proxy shape (illustrative):

```vala
public class RemoteWindow : GLib.Object {
    public uint64 object_id { get; construct; }
    public string title { get; set; default = ""; }
    public bool is_maximized { get; set; default = false; }

    public signal void closed();

    public async void minimize() throws GLib.Error {
        yield RpcBridge.call(this.object_id, "minimize");
    }
}
```

## Exit

- Nested: compositor + Vala panel + `gedit`.
- Panel click changes window state in compositor.
- `kill -9` panel PID → nested `gedit` stays interactive; compositor window stays open.
- Relaunch panel → `Daemon.hello` + `Display.list_windows` → redraw from existing handles.

---

## Nested crash test

1. Nested compositor + panel + `gedit`.
2. Kill **only** panel PID.
3. Compositor and `gedit` stay up.
4. Relaunch panel; bar redraws from `list_windows`.
