## Agent rule: do not change the user’s session

Same as **0.1** / **0.5** — nested tests only.

---

## Principle

**🔷** Add any missing letters on `OLLMrpc.args`. Generated stubs always pack with that helper. No second packing path.

**🔷** **`f`** → `float` / `set_float`. Everything else already has a letter (`i` enum, `u` flags, `o` object, `ay` boxed bytes, …).

**🔷** `Request` / `Response` property is **`args`**, not `values`.

**🚫** Fallback `GLib.Value` boxing when a letter is missing — extend the alphabet instead.

```vala
Runtime.call_values("Meta-Window.change_workspace", this, OLLMrpc.args("o", workspace));
```

---

## Do

- **libocrpc:** add `f` on `OLLMrpc.args`; FLAGS convert with `get_uint()`. **✔️**
- **This repo:** generator emits `OLLMrpc.args("$(sig)", $(packed))`; Runtime takes that list onto `req.args`; rename remaining `.values`. **✔️**
