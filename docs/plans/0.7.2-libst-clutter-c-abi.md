## Problem

Vendored **`libst-16`** is C against mutter’s Clutter **C ABI** (`clutter_event_get_button`, `clutter_paint_context_*`, …).

Stub Clutter in `libmutter-rpc-16.so` already exports ~**1237** `clutter_*` symbols with normal Vala names. **libst** still misses **38** `clutter_*` entry points (plus Cogl/Atk that stock libs already provide).

| Link undefined | Count | Fix |
| --- | ---: | --- |
| `clutter_*` | **38** | Emit / override in stub Clutter (this plan) |
| `cogl_*` | 45 | **🔷** Link stock `mutter-cogl-16` from client-libs |
| `atk_*` | 8 | **🔷** Link stock `atk` from client-libs |

**ℹ️** All **38** appear in `Clutter-16.gir` with matching `c:identifier=…`. Zero of them are in today’s stub `.so` (wrong surface, not wrong rename).

**ℹ️** `PaintContext` / `PickContext` / `PaintVolume` / `ActorBox` already appear in `Clutter_generated.vala` as thin **structs** with little or no method emit — St needs the **record methods** as C symbols.

---

## Why Event was not generated (before Phase A)

GIR `Event` is a **union**; the generator had no `case UNION`, so methods never emitted. An empty `class Event` override existed for Meta/`null`. Wire already treated Event as `"o"`.

**Phase A ✔️:** generator emits Event as a class + instance methods; empty override removed. Nested union `<function>`s denied to avoid `clutter_event_*` clashes with ns stubs.

## Goal

**🔷** `libst-16.so` **links** against `libmutter-rpc-16` (stub Clutter) + stock Cogl/Atk.

**🔷** Attack order: **Event → Paint** (and pick/volume with paint), then actor box/iter leftovers, then shader.

**🔷** Generated / overridden methods may use the normal **`not_wired` → `GLib.error`** body (or no-op where safe) — link proof before RPC behaviour.

**🚫** Full remote paint/GL correctness. **🚫** Stock `libmutter-clutter` back on the client Vala/link line for St.

**🚫** Partial “leased vs local” Clutter dual-stack (user rejected as end state).

## Generator / emit notes

**🔷** Type emit policy lives in **`src/gi-stub-gen/Clutter.overrides`** (same file shape as `Meta.overrides`), not hardcoded in `Generator.vala`:

| Key | Example types | Effect |
| --- | --- | --- |
| `emit=union-as-class` | `Event` | GIR union → `class … : GLib.Object` + methods |
| `wire_as=gobject` | `Event` | Wire / lease path treats union as `"o"` |
| `emit=opaque-as-class` | `PaintContext`, … | size-0 record → class + methods |
| `emit=struct-methods` | `ActorBox`, `ActorIter` | sized struct fields + GIR methods (C ABI stubs) |

Hand bodies / cnames: **`src/gi-stub/overrides-clutter/{Type}.override.vala`**. Deny / noop: **`Clutter.deny`**.

**🔷** After each phase: `ninja … libst-16.so` and count remaining `undefined reference to \`clutter_`.
