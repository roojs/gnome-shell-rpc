## Purpose

Run **import / `GObject.registerClass` smokes** without nested Mutter.

**🔷** Thin `gi-rpc-mock` executable: socket + **Ffi** (`RPC-Daemon`, …) + **`Gi.register`** + **`Request.register_mock(HelperMock)`**.

**🚫** Real `mutter-rpc` never calls `register_mock`. Not a compositor substitute.

---

## How libocrpc mock mode works (shipped RPC-1.7)

**Calling `register_mock` switches the server into mock mode.** You do **not** implement or call `GiMock` yourself — it is internal to libocrpc.

```
Ffi  →  RPC-Daemon, RPC-Live-Callback.*, …
Helper  →  your MockDispatch object (return true if handled)
GiMock  →  automatic when helper returns false (GIR typed empties, no C invoke)
```

**Real compositor** (no `register_mock`):

```
Ffi  →  …
Gi   →  real g_function_info_invoke
```

**Your job in this repo:** one **`HelperMock`** class — `switch (request.method)` for `Helper-*`, `RPC-Bootstrap.*`, etc. Return **`true`** + `reply()` when matched. Return **`false`** for everything else → libocrpc runs **`GiMock`** for you.

## Architecture

```
gi-rpc-mock                         gnome-shell-rpc / gjs-embed
───────────                         ───────────────────────────
Gi.register(Meta|Clutter|St)   ←→   stub .so → Runtime.call_values
Request.register(RPC-Daemon)        import panel.js / registerClass
Request.register_mock(HelperMock)
  true  → Helper switch handles call
  false → GiMock (inside Request.dispatch)
```

| Call kind | Handler |
| --- | --- |
| `RPC-Daemon.*`, `RPC-Live-Callback.*` | **Ffi** |
| `Helper-*`, `RPC-Bootstrap.*`, … | **`HelperMock.dispatch`** — return **true** |
| `Meta-*`, `St-*`, `Clutter.*`, … | **`GiMock`** (libocrpc) — helper returns **false** |

Boot order: **`Gi.register("Meta"|"Clutter"|"St", "16")`** then **`register_mock`** (GiMock uses same `Gi.types` / `namespaces` lookup as real Gi).
