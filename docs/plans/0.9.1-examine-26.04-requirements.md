### 3. Clutter.Stage paint

- `paint_to_buffer`, `paint_to_content`, and `paint_to_framebuffer` each gained a `ColorState` argument.
- The relay calls `paint_to_buffer` from `src/server/libmutter-clutter-16/ClutterStage.vala`, `src/client/libmutter-clutter-rpc-16/overrides/Stage.override.vala`, and `src/client/libshell-16/Screenshot.vala`.

### 4. Meta.Window maximize

- `get_maximized` is gone. `src/server/libmutter-16/Display.vala` calls it. The replacement is `is_maximized`.
- `maximize` and `unmaximize` no longer take `MaximizeFlags`.

### 5. Meta.WaylandClient

- `spawnv` is gone. The relay is `src/server/libmutter-16/WaylandClient.vala` and `src/client/libmutter-rpc-16/overrides/WaylandClient.override.vala`.
- The replacement constructor is `new_subprocess`.
- `hide_from_window_list` and `show_in_window_list` moved onto `Meta.Window`.
- `make_desktop` and `make_dock` are gone.

### 6. Meta.Display cursor

- `set_cursor` is gone, and the `Meta.Cursor` type is gone. `src/server/rpc/SpawnClient.vala` calls `set_cursor`.
- Cursor is now `Clutter.Cursor` / `Clutter.CursorType`. `Clutter.Actor` gained `cursor-type`.
- The signal `modifiers-accelerator-activated` no longer returns a boolean.

### 7. Shell.App

- `app-info` / `get_app_info` now returns `GioUnix.DesktopAppInfo`.
- `src/client/libshell-16/App.vala` and `src/client/libshell-16/AppSystem.vala` still use `GLib.DesktopAppInfo`.

### Later

- ℹ️ `St.FocusManager.get_group` now takes a `Clutter.Actor` instead of an `St.Widget`. The FocusManager relay does not call `get_group`.
- ℹ️ `Clutter.InputDevice` `product-id` and `vendor-id` changed from string to uint. The relay does not read them.
- ℹ️ `Clutter.Actor` method signatures the relay already uses did not change.
- ℹ️ `Cogl`, `Mtk`, `Gvc`, and `Shew` have no API change on a class this tree relays.
