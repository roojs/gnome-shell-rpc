# 1.3 — Boxed type generator

**Related:**

## Purpose

- 🔷 A separate class generates the boxed-type overrides, called as a step of `emit`.
- 🔷 A sized record is byte-copied, including notify and signal.
- 🔷 A record with no size is not byte-copied.
- 🔷 An unclassified boxed type fails `emit`.

---

## Phase 1 — Boxed type step

- 🔷 The class is not a subclass of `Generator`.
  - ⏳ The generation code stays in that class.
- 🔷 The constructor takes the `Generator`.
  - ✔️ `BoxedType(Generator)`.
- 🔷 `Generator` is the manager.
  - ⏳ It calls this class as a step of the existing `emit`.
  - ⏳ There is no separate command and no extra argument that emits boxed types on their own.
- 🔷 Later the same manager calls a class generator, a method generator, and a property generator, and it holds the shared utility functions.
  - ⏳ This plan only splits out the boxed-type generator.
- 🔷 It only generates boxed-type overrides.
- 🔷 A record with a size is copied as bytes and rebuilt on the other side.
  - ⏳ Notify and signal do that too.
  - ⏳ Do not list the members.
- 🔷 The copy is the Vala assignment `emit_boxed_bytes` already emits.
  - ⏳ `uint8[]` of `sizeof(T)`.
  - ⏳ `*((T*) data) = value`, then `pack_bytes`.
  - ⏳ The other side is `unpack_bytes`, then a `GLib.Value` of that type.
- 🔷 `pack_bytes` and `unpack_bytes` live on `OLLMrpc.Bin.TypeOverride`.
- 🔷 A record with no size is not byte-copied.
- 🔷 Every boxed type is either generated, already covered by an override, or named in a deny (or the same kind of definition) that says we are not generating it.
  - ⏳ If it is none of those, `emit` fails and names the type.
  - ⏳ A missing decision is not a skip.
- 💩 Which records qualify still comes from `g_struct_info_get_size`.
  - ⏳ Greater than 0 is copied.
  - ⏳ The emitted length is `sizeof` of the Vala type.
- 💩 A null source is `sizeof(T)` zero bytes.
  - ⏳ `consumed` is 1.
- 💩 Size 0 packs an empty list.
  - ⏳ `consumed` is 0.
  - ⏳ The value is an empty `GLib.Value` of that GType.
  - ⏳ That stops `StreamValue` throwing.
  - ⏳ It does not `Bin.register`.
- 💩 Walk registered structs.
  - ⏳ `g_registered_type_info_get_type_init` is set.
  - ⏳ A gtype struct, a foreign record, a name ending in `Class` or `Private`, or a union is still a boxed type in this check.
  - ⏳ It is generated, already overridden, or named in a deny.
  - ⏳ Otherwise `emit` fails.
- ℹ️ Existing lists the emit already reads: `Clutter.deny`, `Meta.deny`, `St.deny`, and `{Type}.override.vala`.
- ℹ️ Method returns already copy the struct into `GLib.Bytes` (`Generator.type_is_boxed_blob`, wire `ay`).
- ℹ️ `StreamValue` already writes a `GLib.Bytes` value.
- 💩 `✔️` Add `BoxedType`.
  - ✔️ `gi_stub_gen` in `src/meson.build` compiles the new file.
  - ✔️ `src/generator/namespace.vala` names the class next to `Generator` and `HeaderGenerator`.
  - ✔️ `Generator.emit` calls it.
  - ✔️ The CLI stays `emit`.
- 💩 `⏳` Prove the emit.
  - ⏳ `gi-stub-gen emit Clutter 16` also writes the boxed-type overrides.
  - ⏳ Margin copies 16 bytes.
  - ⏳ `EventSequence` packs nothing.
  - ⏳ A boxed type with no override and no deny makes that emit fail and names the type.

## Phase 2 — Hand files this emit replaces

- 💩 One class, flags for each output file.
  - ⏳ Vala namespace.
  - ⏳ `global::` on the server, where the namespace collides with `Clutter`.
  - ⏳ `internal` in client `Shell`, `public` on the server.
  - ⏳ Extra typelibs: `Graphene:1.0`, `Cogl:16`, `St:16`.
  - ⏳ Server `St` has no vapi, so `extern` `st_*_get_type` and the typelib size.
- 💩 `⏳` Delete the hand pack of each registered struct whose size is greater than 0.
  - ⏳ `src/server/libmutter-clutter-16/BoxedTypeOverrides.vala`
    - Margin, Perspective, `Cogl.Color`, Point3D
    - Graphene matrix, vec, quaternion, box, euler, plane, ray, sphere, triangle, quad, frustum
  - ⏳ `src/server/libst-16/BoxedTypeOverrides.vala`
    - `IconColors` (16), `Shadow` (48)
  - ⏳ `src/client/libshell-16/BoxedTypeOverrides.vala`
    - the same records, one client file
  - ⏳ `ActorBoxOverride.vala` (16), both sides
  - ⏳ `GraphenePointOverride.vala` (8), both sides
  - ⏳ `GrapheneSizeOverride.vala` (8), both sides
  - ⏳ `GrapheneRectOverride.vala` (16), both sides
  - ⏳ `RectangleOverride.vala` (`Mtk.Rectangle`, 16), both sides
  - ⏳ `BarrierEventOverride.vala` (`Meta.BarrierEvent`, 56, no pointer fields), both sides
- 💩 Those generated files also emit the size-0 empties already packed as nothing.
  - ⏳ `EventSequence`, `PaintContext`, `PaintVolume`, `FrameClosure`, `MatrixEntry`, `ShadowHelper`
- 💩 Do not emit a second override over a hand projection.
  - ⏳ These stay as the override or deny Phase 1 requires, so `emit` does not fail on them and does not replace them.
  - ⏳ `KeyBinding` — size 0, getters
  - ⏳ `Region` — size 0, rectangle walk
  - ⏳ `Frame` — size 0, stays on `Gi.register`
  - ⏳ `PickContext` and `InputDevice` — existing overrides, not this image
  - ⏳ `Event` — union, stays `ClutterEventOverride`
- 💩 Registration stays `register_boxed_types()`.
  - ⏳ Called from `Gsr.Server.Clutter`, `Gsr.Server.St`, and `Shell.register`.
  - ⏳ ActorBox, Point, Size, Rect, Rectangle, and BarrierEvent move into that function.
  - ⏳ Their hand `TypeOverride.register` lines come out.
- 💩 `⏳` The same `emit` that writes the stubs also writes these files.
  - ⏳ Server Clutter, Graphene, and Cogl.
  - ⏳ Server St.
  - ⏳ Client Shell.
  - ⏳ Meta `BarrierEvent`.
  - ⏳ Mtk `Rectangle`.
- 💩 `⏳` `ninja -C build src/gsr-client src/gsr-server` exits 0.
  - ⏳ `register_boxed_types` is the only registration for those GTypes.

## Phase 3 — Pack check

- 💩 ✔️ A gate checks `TypeOverride.pack` for the Vala assignment Phase 1 emits.
  - ✔️ `Graphene.Size` is one `GLib.Bytes` of 8 bytes.
  - ✔️ `Clutter.Margin` is one `GLib.Bytes` of 16 bytes.
  - ✔️ Null packs that many zeros.
  - ✔️ A size-0 record packs an empty list.
- 💩 ✔️ Client and server use the same length for the same GType.
  - ✔️ Both compile the generated file. `tests/boxed-pack-gate` checks those lengths.
  - ✔️ `Meta.BarrierEvent` stays a hand override. Vala binds it as a class, so the struct assignment does not compile.

## LLM notes

- 🚫 `Bin.register` of these GTypes. An alias payload is four zero bytes and replaces the `Gi.scalar` copy.
- 🚫 Inventing a GType for `Clutter.Colorimetry`, `Clutter.EOTF`, `Clutter.Luminance`, `Cogl.DepthState`, or the disguised records in the bug.
- 🚫 Field lists, getters, `to_float`, or per-member recipes.
- 🚫 `GLib.Memory.copy`, `malloc`, or `take_boxed` as the copy. The copy is the Vala assignment.
- 🚫 Skipping a boxed type that has no override and no deny. `emit` fails and names it.
- 🚫 A subclass of `Generator`.
- 🚫 A separate `emit-boxed` command, or an argument whose only job is to emit boxed types.
- 🚫 Splitting out a class generator, a method generator, or a property generator in this plan.
- 🚫 Editing `libocrpc`.
- 🚫 `meson install`, or logging this build into the Ubuntu VM.
