## Stock (what JS thinks it has)

```js
// DING / rooterm — stock mutter
let client = new Meta.WaylandClient(context, launcher);
let proc = client.spawnv(display, argv);   // Gio.Subprocess
proc.get_stdout_pipe().read_bytes(...);
await proc.wait_async(null);
proc.force_exit();
```

Spawn injects `WAYLAND_SOCKET` into **mutter**. Real process object lives in
the compositor — not in the shell.

---

## What we do instead

```text
gnome-shell-rpc                    mutter-rpc
─────────────────                  ────────────────────────────
WaylandClient.spawnv()
  → Helper-WaylandClient.spawnv  → Meta.WaylandClient.spawnv()
                                   GLib.Subprocess  (real)
  ← reply + stdout FD (SCM)
RpcSubprocess(lid, fd)             this.subprocess = proc
  wait / signal  → Helper-*     →  proc.wait / send_signal
  get_stdout_pipe() = local FD
```

Files:

- helper: `src/rpc/helper/WaylandClient.vala`
- client override: `src/gi-stub/overrides/WaylandClient.override.vala`
- peer: `src/gi-stub/RpcSubprocess.vala`

## Issue 1 — one lease for client + process

```vala
// same lid as WaylandClient
new RpcSubprocess(this.rpc_lid, stdout_fd);

// peer wait → Helper-WaylandClient.wait(self = that row)
GnomeShellRpc.call_value("Helper-WaylandClient.wait", this);
```

```text
Helper row holds:
  peer:       Meta.WaylandClient
  subprocess: GLib.Subprocess     ← one slot

Stock mutter: one spawn per WaylandClient. Fine.
Second process / separate Subprocess lid → need another lease. 💩 until forced.
```

## Issue 2 — “hooks” are methods + FDs, not signal relay

```vala
// ✔️ already — control plane (RPC)
wait_async / get_if_exited / get_exit_status / send_signal / force_exit

// ✔️ already — data plane (local after FD pass)
get_stdout_pipe() → UnixInputStream(stdout_fd)

// no Gio.Subprocess::exited to rebroadcast
// WaylandClient::client-destroyed is a different object — only if needed
```

Wrong mental model:

```text
❌  mutter Subprocess signal  →  wire emit  →  shell handler
✔️  shell calls peer method   →  Helper RPC →  real Subprocess
✔️  shell reads local pipe FD (handed once at spawn)
```
