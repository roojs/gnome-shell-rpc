## Model (one picture)

**✔️** in libocrpc and B2 / B1 / B3 consumers (including nested idle-smoke / key-smoke / transient-smoke). **⏳** = `foreach_ancestor` / `Hook.drop` / `Clutter.Event` on B1 notify.

```
client: RPC-Live-Callback.register  →  callback_id     ✔️ Runtime.callback_bind
        (client table: id → InvokeRow wrapping lambda)

client Override: add_idle_watch → Helper RPC           ✔️ IdleMonitor.override.vala
        args: interval_msec + callback_id

server IdleMonitor.Helper                              ✔️
        lookup Hook; mutter add_idle_watch(lambda capturing row)

mutter: idle → lambda → Hook.emit                      ✔️ capturing IdleMonitorWatchFunc
server: Live.Invoke { id, reply_id, args }             ✔️

client: Invoke → run lambda                            ✔️ demux
client: Idle.add → RPC-Live-Callback.reply             ✔️ (not sync on the read watch)

server: Hook.emit wait completes → mutter              ✔️
mutter: DestroyNotify → Hook.drop                      ⏳ unused on B2 — Vala owned callback, no C user_data
```

**ℹ️** 8.3.6 did **not** put reply on stock `Notification`. Invoke is **`Live.Invoke`**; answer is **`RPC-Live-Callback.reply`**. Subscribe stays fire-and-forget.

| Live type | Register how | Server → client | Client → server | This repo boot |
| --- | --- | --- | --- | --- |
| `RPC-Live-Remote` | ref / unref | — | — | **✔️** |
| `RPC-Live-Subscribe` | `signal` / `unsubscribe` | `Notification` (no reply) | — | **✔️** |
| **`RPC-Live-Callback`** | **`register` / `unregister`** | **`Live.Invoke`** | **`reply`** | **✔️** `Server.start()` |

**Lifecycle:** register → use (typelib + invoke + **reply**) → unregister.

#### Add — `src/gi-stub/Runtime.vala`

**Named methods:** `callback_bind`, `InvokeHandler`.

**ℹ️** Vala will not store a capturing delegate in `Gee.HashMap` (`Delegates with target are not supported as generic type arguments`). Landed table is `HashMap<int, InvokeRow>` — a private `GObject` that holds the `owned InvokeHandler`.

```vala
public delegate void InvokeHandler(OLLMrpc.Live.Invoke call);

private class InvokeRow : GLib.Object
{
	public InvokeHandler handler;
}

private static Gee.HashMap<int, InvokeRow>? handlers = null;

public static uint64 callback_bind(owned InvokeHandler handler)
{
	Runtime.register();
	if (Runtime.handlers == null) {
		Runtime.handlers = new Gee.HashMap<int, InvokeRow>();
	}
	var response = Runtime.call_values("RPC-Live-Callback.register", null);
	var id = (int) response.args.get(0).get_uint64();
	var row = new InvokeRow();
	row.handler = (owned) handler;
	Runtime.handlers.set(id, row);
	return (uint64) id;
}
```

**Replace with** — end of `Runtime.register()`, after `connected = true`. **✔️** Nested idle-smoke: reply is **`GLib.Idle.add`**, not a sync `call_values` on the read watch (that deadlocks).

```vala
Runtime.client.invoke.connect((call) => {
	if (Runtime.handlers != null && Runtime.handlers.has_key(call.id)) {
		Runtime.handlers.get(call.id).handler(call);
	} else {
		GLib.warning("Live.Invoke id=%d has no handler", call.id);
	}
	var reply_id = (uint64) call.reply_id;
	GLib.Idle.add(() => {
		Runtime.call_values(
			"RPC-Live-Callback.reply",
			null,
			OLLMrpc.args("t", reply_id)
		);
		return GLib.Source.REMOVE;
	});
});
```

**🚫** Do not demux `Invoke` as a `Notification`. **🚫** Do not put the handler table in libocrpc.

#### Add — `src/rpc/helper/IdleMonitor.vala`

**ℹ️** Mutter Vala `IdleMonitorWatchFunc` is `(IdleMonitor, uint)` — no `user_data` / `DestroyNotify`. The sketch below of `idle_watch, row, Hook.drop` **does not compile**. Landed trampoline is a capturing lambda that calls `row.emit(...)`. Client handler table can leak until `RPC-Live-Callback.unregister` (no `Hook.drop` on this path).

```vala
namespace GnomeShellRpc.Rpc.Helper
{
	public class IdleMonitor : GLib.Object
	{
		public static void register()
		{
			OLLMrpc.Request.add_class(
				"Helper-IdleMonitor", typeof(IdleMonitor),
				"add_idle_watch", "tt",
				"add_user_active_watch", "t",
				null
			);
			OLLMrpc.Request.register_live(
				"Helper-IdleMonitor", new IdleMonitor());
		}

		public void add_idle_watch(
			OLLMrpc.Request request,
			uint64 interval_msec,
			uint64 callback_id
		) {
			var monitor = (Meta.IdleMonitor) request.connection.leases.get(
				(int) request.lease_id);
			var row = request.connection.callbacks.get((int) callback_id);
			var watch_id = monitor.add_idle_watch(
				interval_msec, idle_watch, row, OLLMrpc.Live.Hook.drop);
			request.reply(new OLLMrpc.Response() {
				id = request.id,
				args = OLLMrpc.args("u", watch_id)
			});
		}

		public void add_user_active_watch(
			OLLMrpc.Request request,
			uint64 callback_id
		) {
			var monitor = (Meta.IdleMonitor) request.connection.leases.get(
				(int) request.lease_id);
			var row = request.connection.callbacks.get((int) callback_id);
			var watch_id = monitor.add_user_active_watch(
				idle_watch, row, OLLMrpc.Live.Hook.drop);
			request.reply(new OLLMrpc.Response() {
				id = request.id,
				args = OLLMrpc.args("u", watch_id)
			});
		}

		public static void idle_watch(
			Meta.IdleMonitor monitor,
			uint32 watch_id,
			void* user_data
		) {
			var row = (OLLMrpc.Live.Hook) user_data;
			row.emit(OLLMrpc.args(
				"tu",
				row.connection.export(monitor),
				watch_id
			));
		}
	}
}
```

### 4c. Smoke (nested only)

#### Add — `src/gjs-embed/idle-smoke.js`

```js
imports.gi.versions.Meta = '16';
const { GLib, Meta } = imports.gi;

function main() {
	const monitor = Meta.get_display().get_idle_monitor(0);
	let fired = false;
	const id = monitor.add_idle_watch(1, () => {
		fired = true;
	});
	log('idle-smoke: watch id=' + id);
	const loop = new GLib.MainLoop(null, false);
	GLib.timeout_add(GLib.PRIORITY_DEFAULT, 2000, () => {
		if (!fired)
			throw new Error('idle-smoke: watch did not fire');
		monitor.remove_watch(id);
		loop.quit();
		return GLib.SOURCE_REMOVE;
	});
	loop.run();
}
main();
```

**ℹ️** Nested mutter only. Spawn: `GI_META_SMOKE=idle-smoke` (same compositor `spawn_client` as clutter-smoke). `remove_watch` is already generated `call_values`. 1 ms idle may not fire if the nested session is busy — lengthen if needed.
