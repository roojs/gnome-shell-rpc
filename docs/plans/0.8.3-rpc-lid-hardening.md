# 0.8.3 — Harden `rpc_lid` from GJS (deferred)

**Status:** **DEFERRED** — after **0.8** interaction bar. Do **not** start
while Phase B / chrome prove is in flight.

**User goal:** keep wire lease handles as RPC plumbing, not something GJS
(or extensions) can casually read or reassign.

**Context:** `OLLMrpc.Live.Handle.rpc_lid` (GObject name `rpc-lid`) is a
construct property on every leased stub so Bin live-decode can
`Object.new(…, "rpc-lid", handle)` and stub construct can skip remint.
Discussed 2026-09-14 in-session — stock shell JS does not name it; typelib
often omits it; the GType still installs it **readable + writable**.

**🚫** Diverting 0.8 A/B into this.  
**🚫** OLLMchat / libocrpc edits from this tree without a FAIL gate + bug.  
**🚫** Changing stub call sites until the Handle/Bin contract is decided.

---

## Why

| Fact | Risk |
| ---- | ---- |
| `g_param_spec_uint64 ("rpc-lid", … READABLE \| WRITABLE \| CONSTRUCT)` on Handle implementors | Anything that sets GObject props by name can retarget a proxy to another lease |
| Not a stock Meta/Clutter/St symbol | Normal chrome will not use it; not “API pollution” for layout.js |
| Often absent from our typelibs | GJS GI path usually blind — **not** the same as “not on the GType” |

**Done when:** GJS cannot assign `rpc-lid` through normal property APIs;
lease inject for Bin/overrides still works; nested prove still greens A/B
markers you care about at that time.

---

## Options (pick later)

| # | Approach | Where | Notes |
| - | -------- | ----- | ----- |
| H1 | `[CCode (gir = false)]` on `rpc_lid` | Generator + hand stubs / Handle | Hides from GIR/typelib only; GObject prop remains |
| H2 | Construct-only / non-writable after construct | `Live.Handle` + Vala emit | Stops JS reassignment; overrides that assign `rpc_lid` must still compile |
| H3 | Drop GObject property; private field + Vala accessors | libocrpc Bin + Handle | Bin needs a non-`Object.new` inject (dedicated setter / qdata) |
| H4 | Quark / `qdata` instead of `"rpc-lid"` | libocrpc Bin + Handle | Invisible to GObject property APIs; largest contract change |

**Preferred direction (provisional):** **H2** first if enough; **H3/H4** only
if writable construct props remain a real footgun after H2.

---

## Prove (when opened)

1. Nested weston prove still reaches current A/B bar.  
2. From a tiny GJS probe: setting `rpc-lid` on a stub fails or is a no-op
   (exact assert depends on H1–H4).  
3. Wire-decode of leased objects still sets the handle (BackgroundActor /
   Widget mint path).

## Out of scope

- Extension sandboxing generally.  
- 0.8.1 / 0.8.2 performance or hook-registry work.
