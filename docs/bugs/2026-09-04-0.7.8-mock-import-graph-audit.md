## The bug

During real shell startup, memory inside the JS engine gets corrupted. The process aborts with `double free or corruption (out)`.

---

## What we know

- **Repro:** `./scripts/gi-rpc-smoke.sh run` (real `init.js`, fake compositor).
- **Trace:** `GI_RPC_REGISTER_CLASS_TRACE=1 ./scripts/gi-rpc-smoke.sh run` — last lines before crash.
- **Pin:** crash after **`Message`**, **`NotificationMessage`**, **`MediaMessage`** register (#36–#38).
- **Earlier fix in same file:** `MessageView` needed `St.Scrollable` on `St.Viewport` stub.
