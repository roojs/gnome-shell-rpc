## Bug (closed)

During mock `init.js` boot, the process aborted with `double free or corruption (out)` while registering **`Message extends St.Button`** in `messageList.js` (trace #36–#37).

---

## Fix

GIR `StButtonClass` has `clicked` and `transition` vfunc slots; generated stub had neither. Added to `src/gi-stub-gen/St.overrides`:

```
Namespace emit_class_slots=1
```

Same generator knob as Clutter. Regenerates `St.Button` with `virtual void clicked()` / `transition()` in class-struct order.

**Pass bar (mock):** `./scripts/gi-rpc-smoke.sh run` — no `double free` / `Aborted` (verified 5/5).
