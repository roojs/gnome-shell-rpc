### 1. `src/client/libshell-16/polkit-authentication-agent-signals.c` — five-parameter signal

**Why:** Vala’s `signal` for `string[]` registers a sixth `int`. GJS walks that count and reads past the typelib.

**Where:** New file.

**Depends on:** none.

#### Add

New file.

```c
#include <glib-object.h>

/*
 * Stock Shell.PolkitAuthenticationAgent.initiate: five parameters,
 * last is G_TYPE_STRV. A Vala signal appends an int length.
 */
void
shell_polkit_authentication_agent_register_initiate(GType type)
{
	if (g_signal_lookup("initiate", type) != 0)
		return;
	g_signal_new("initiate",
		type,
		G_SIGNAL_RUN_LAST,
		0,
		NULL,
		NULL,
		NULL,
		G_TYPE_NONE,
		5,
		G_TYPE_STRING,
		G_TYPE_STRING,
		G_TYPE_STRING,
		G_TYPE_STRING,
		G_TYPE_STRV);
}
```
