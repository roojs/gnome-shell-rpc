## Bug (closed)

`gi-rpc-smoke.sh run` smokes sat in `Meta.Context.run_main_loop()` until an external `timeout 18` killed them.

---

## Fix

- **`scripts/gi-rpc-smoke.sh`:** `kill_mock_server` after client exits; EXIT trap on early failure.
- **Client:** `Context.override.vala` — RPC `Meta-Context.terminate`, then `loop.quit()`.
- **Mock:** `HelperMock.vala` — `reply_void` on terminate; optional hard exit on happy path.

**Pass bar:** default smoke completes in ~1–2 s; mock killed when client returns.
