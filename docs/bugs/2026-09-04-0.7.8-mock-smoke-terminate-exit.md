**Last updated:** 2026-09-04

---

## Symptom

`gi-rpc-smoke.sh run` smokes sit in `Meta.Context.run_main_loop()` until **`timeout 18`** kills them. The client never exits cleanly; bisect loops pay 18 s per iteration for no reason.

```bash
./scripts/gi-rpc-smoke.sh run src/gjs-embed/terminate-probe-smoke.js
# expect: left run_main_loop, exit 0, < 2 s — not timeout 18
```

---

## Root cause

Two separate problems:

1. **Happy path:** smokes that finish normally never call **`terminate()`** — client sits in `run_main_loop()` until external `timeout`.
2. **Crash / abort path:** client exits without **`Meta-Context.terminate`** — mock keeps listening unless something else kills it.

---

## Required behaviour

### When the smoke finishes normally

1. Smoke calls **`global.context.terminate()`** (stock API).
2. Client override RPCs **`Meta-Context.terminate`**, then quits `gsr-client-main-loop`.
3. **Live `mutter-rpc`:** void ack only — compositor keeps running.
4. **`gi-rpc-mock` on `Meta-Context.terminate`** — strict order, inside `HelperMock`:

   1. **`reply_void`** — send void ack **now**, still inside RPC dispatch (reply flushed before handler returns).
   2. **`GLib.Idle.add(...)`** — schedule one shot; do **not** call exit from dispatch.
   3. **Idle callback:** hard process exit (`GLib.Process.exit(0)`).

   **🚫 Not acceptable on mock:**

   - `MainLoop.quit()` / “idle-quit the loop” / waiting for `main_loop.run()` to return
   - Any graceful teardown — ack, next idle tick, **hard exit**

### When the client exits without terminate (crash, abort, missing smoke exit)

**`gi-rpc-smoke.sh run`** is responsible: as soon as **`gnome-shell-rpc` returns**, if **`gi-rpc-mock`** is still running, **kill it**. No RPC needed on this path — POSIX kill is fine.

This is the **interim safety net** until every smoke calls `terminate()`. The script already does this via `kill_mock_server` after the client line (+ EXIT trap for early failures).

```
normal:  smoke → terminate() → RPC
           mock: reply_void → Idle.add → _exit(0)
           client: loop.quit() → gnome-shell-rpc exits
           script: kill mock only if still alive (crash path)
crash:   client dies → script kill mock
hang:    client stuck in run_main_loop() — still broken until smoke calls terminate()
```

5. **`gi-rpc-smoke.sh`:** `kill_mock_server` after client; EXIT trap if `cmd_run` fails before client runs.

---

## Do not add

- **`Helper-Smoke`** or any smoke-specific Helper wire
- **`GI_RPC_MOCK`** / hello peer detection / env-var gating on the client
- **`quit_smoke()`** unless it is literally `terminate()` with no extra layer

---

## Wrong turns already tried (do not repeat)

| Attempt | Why wrong |
| --- | --- |
| `Helper-Smoke.quit` RPC | Smokes are not a Helper problem |
| `GI_RPC_MOCK=1` env gating | Client should always RPC terminate; servers differ |
| Shell `kill` as **only** mock shutdown on happy path | Mock should `_exit` on terminate RPC when smokes behave |
| `MainLoop.quit()` on mock terminate | Wrong — use `GLib.Idle.add` then hard exit |
| Client-only `terminate()` with no RPC | Mock never told to exit on happy path |
